[5-5 title sec-7-differentials default_required]
Differentials

[7-16 p sec-7-differentials default_required]
made the total derivative into a
    linear function:
    Df(\mathbf p)(\Delta\mathbf x).
    It takes a small displacement and returns the predicted change in f.
     already gave us the simplest linear functions:
    dx,\qquad dy,\qquad dz.
    They read off components of a vector. Differentials combine these component-readers with the
    partial derivatives.

[19-19 title c7s4-subsec-differential-as-linear-function default_required]
The differential as a linear function of small changes

[21-25 p c7s4-subsec-differential-as-linear-function default_required]
Return to the bakery cost model from :
      C(u,v)=400+3u+4v+0.01uv,
      where u is the number of sourdough loaves and v is the number of rye loaves.

[27-36 p c7s4-subsec-differential-as-linear-function default_required]
We computed
      C_u(u,v)=3+0.01v, \qquad C_v(u,v)=4+0.01u.
      At
      (u,v)=(200,100),
      these become
      C_u(200,100)=4, \qquad C_v(200,100)=6.
      So the total derivative at this production level is
      DC(200,100)(\Delta u,\Delta v) = 4\Delta u+6\Delta v.

[38-44 p c7s4-subsec-differential-as-linear-function default_required]
Suppose the bakery changes production by
      \Delta u=4, \qquad \Delta v=3.
      The linear prediction is
      4(4)+6(3)=34.
      So the cost should increase by about 34 dollars.

[46-59 p c7s4-subsec-differential-as-linear-function default_required]
The exact change is
      
        \amp C(200+\Delta u,100+\Delta v)-C(200,100)
        \amp\qquad = 4\Delta u+6\Delta v+0.01\Delta u\Delta v.
      
      For
      \Delta u=4,\qquad \Delta v=3,
      this gives
      34+0.01(4)(3)=34.12.
      The differential predicted the first-order part. The extra
      0.12
      came from the product of the two small changes.

[62-62 title c7s4-def-differential-at-a-point default_required]
Differential at a point

[64-69 p c7s4-def-differential-at-a-point default_required]
If f is differentiable at \mathbf p, then the
          differential of f at \mathbf p is the total derivative:
          \boxed{ df_{\mathbf p}=Df(\mathbf p). }
          Thus df_{\mathbf p} is a linear function of a small displacement.

[73-76 p c7s4-subsec-differential-as-linear-function default_required]
For the bakery,
      dC_{(200,100)}(\Delta u,\Delta v) = 4\Delta u+6\Delta v.

[78-78 p c7s4-subsec-differential-as-linear-function default_required]
The letter d is not decoration. It means: take the first-order change.

[81-81 title checkpoint-7-4-df-is-a-function default_required]
A number or a function?

[83-89 p checkpoint-7-4-df-is-a-function default_required]
We could have defined df_{\mathbf p} as the single number 34 we got from the
          bakery, the predicted cost change for one particular move. Instead we kept it as the whole
          linear function df_{\mathbf p}(\Delta u,\Delta v)=4\Delta u+6\Delta v. Why is the
          function the better object? What would we lose if we collapsed df_{\mathbf p} down to a
          tiny number?

[92-96 p checkpoint-7-4-df-is-a-function hint]
A single number answers one question; a function answers infinitely many at once. Ask yourself
          what changes (and what stays the same) if the bakery picks a different step
          (\Delta u,\Delta v).

[102-102 title c7s4-subsec-notation-df default_required]
The notation df=f_x\,dx+f_y\,dy

[104-122 p c7s4-subsec-notation-df default_required]
The symbols
      dx,\qquad dy
      are the coordinate-reading linear functions:
      dx(\Delta x,\Delta y)=\Delta x,
      and
      dy(\Delta x,\Delta y)=\Delta y.
      So if
      f=f(x,y),
      then
      
        df_{(a,b)}(\Delta x,\Delta y) \amp= f_x(a,b)\Delta x+f_y(a,b)\Delta y
        \amp= f_x(a,b)\,dx(\Delta x,\Delta y) + f_y(a,b)\,dy(\Delta x,\Delta y).
      
      This is why we write
      \boxed{ df=f_x\,dx+f_y\,dy. }
      At a specific point,
      \boxed{ df_{(a,b)} = f_x(a,b)\,dx+f_y(a,b)\,dy. }

[157-162 p c7s4-subsec-notation-df default_required]
For functions of three variables,
      \boxed{ df=f_x\,dx+f_y\,dy+f_z\,dz. }
      At the point (a,b,c),
      \boxed{ df_{(a,b,c)} = f_x(a,b,c)\,dx+f_y(a,b,c)\,dy+f_z(a,b,c)\,dz. }

[165-165 title c7s4-ex-hill-differential default_required]
The hill differential

[167-177 p c7s4-ex-hill-differential default_required]
For
          H(x,y)=80+3x-y-\frac14x^2-\frac12y^2,
          we have
          H_x(x,y)=3-\frac12x, \qquad H_y(x,y)=-1-y.
          At
          (2,1),
          H_x(2,1)=2, \qquad H_y(2,1)=-2.
          So
          \boxed{ dH_{(2,1)}=2\,dx-2\,dy. }

[178-189 p c7s4-ex-hill-differential default_required]
If the trail direction is
          \mathbf u=\left(\frac35,\frac45\right),
          then
          
            dH_{(2,1)}(\mathbf u) \amp= 2\,dx(\mathbf u)-2\,dy(\mathbf u)
            \amp= 2\left(\frac35\right)-2\left(\frac45\right)
            \amp= -\frac25.
          
          This is exactly the directional derivative found in
          .

[193-200 p c7s4-subsec-notation-df default_required]
The gradient and the differential contain the same coefficients, but they play different
      roles:
      \nabla f(a,b)=\bigl(f_x(a,b),f_y(a,b)\bigr)
      is a vector, while
      df_{(a,b)}=f_x(a,b)\,dx+f_y(a,b)\,dy
      is a linear function that acts on displacement vectors.

[202-205 p c7s4-subsec-notation-df default_required]
The dot product connects them:
      df_{\mathbf p}(\mathbf h)=\nabla f(\mathbf p)\cdot \mathbf h.

[209-209 title c7s4-subsec-error-estimates default_required]
Error estimates and small-change calculations

[211-219 p c7s4-subsec-error-estimates default_required]
The differential is useful because it is the part of the change we can compute quickly.
      If f is differentiable at \mathbf p, then
      f(\mathbf p+\Delta\mathbf x)-f(\mathbf p) = df_{\mathbf p}(\Delta\mathbf x)+R(\Delta\mathbf x),
      where
      \frac{|R(\Delta\mathbf x)|}{\|\Delta\mathbf x\|}\to0.
      So for small changes,
      \boxed{ \Delta f\approx df. }

[221-224 p c7s4-subsec-error-estimates default_required]
This is the multivariable version of the single-variable estimate
      \Delta y\approx f'(a)\Delta x.

[227-227 title checkpoint-7-4-when-approximation-fails default_required]
When does \Delta f\approx df hold up?

[229-234 p checkpoint-7-4-when-approximation-fails default_required]
In the line f(\mathbf p+\Delta\mathbf x)-f(\mathbf p)=df_{\mathbf p}(\Delta\mathbf x)+R(\Delta\mathbf x),
          the remainder satisfies |R|/\|\Delta\mathbf x\|\to0. Explain in your own words why this
          makes df a good estimate for a small step. Then describe a situation where
          you should not trust \Delta f\approx df, even though the formula is still technically true.

[237-241 p checkpoint-7-4-when-approximation-fails hint]
The condition only says R shrinks faster than \|\Delta\mathbf x\| as the step goes to
          zero, it promises nothing for a large step. Think about the leftover 0.12 and 0.000194
          terms in the worked examples, and what happens to them when the step is no longer small.

[245-251 p c7s4-subsec-error-estimates default_required]
In a numerical small-change calculation, the customary notation dx=0.02
      abbreviates the value of the coordinate measurement on the chosen displacement:
      dx(\Delta\mathbf x)=\Delta x=0.02. Similarly, a numerical df means
      df_{\mathbf p}(\Delta\mathbf x), the predicted change for that displacement.
      The underlying differential remains a linear function, not an infinitesimal number.

[254-254 title c7s4-ex-volume-storage-bin default_required]
Measuring the volume of a storage bin

[256-269 p c7s4-ex-volume-storage-bin default_required]
A rectangular storage bin has side lengths
          x,\qquad y,\qquad z
          in meters. Its volume is
          V(x,y,z)=xyz.
          Then
          V_x=yz, \qquad V_y=xz, \qquad V_z=xy.
          At
          (x,y,z)=(2,3,5),
          we get
          V_x=15, \qquad V_y=10, \qquad V_z=6.
          So
          dV_{(2,3,5)} = 15\,dx+10\,dy+6\,dz.

[270-281 p c7s4-ex-volume-storage-bin default_required]
Suppose the measured side lengths change by
          dx=0.02, \qquad dy=-0.01, \qquad dz=0.03.
          Then
          
            dV \amp= 15(0.02)+10(-0.01)+6(0.03)
            \amp= 0.30-0.10+0.18
            \amp= 0.38.
          
          So the volume changes by about
          0.38\ \text{m}^3.

[282-288 p c7s4-ex-volume-storage-bin default_required]
The exact change is
          (2.02)(2.99)(5.03)-30 = 0.380194.
          The differential gives the first-order part. The missing
          0.000194
          comes from products of the small side-length changes.

[292-295 p c7s4-subsec-error-estimates default_required]
Differentials are often used this way in measurements. If the inputs have small errors,
      the differential estimates the resulting output error.

[298-298 title c7s4-ex-temperature-sensitivity default_required]
Temperature sensitivity

[300-312 p c7s4-ex-temperature-sensitivity default_required]
For the storage-room temperature model
          T(x,y,z)=18+\frac{4}{1+x^2+y^2}-0.7z,
          we found at (1,0,2)
          dT_{(1,0,2)}=-2\,dx-0.7\,dz.
          There is no dy term at that point because
          T_y(1,0,2)=0.
          A small move
          dx=0.02,\qquad dy=-0.03,\qquad dz=0.10
          therefore gives
          dT=-2(0.02)-0.7(0.10)=-0.11.
          The dy-change does not affect the first-order estimate at this particular point.

[316-320 p c7s4-subsec-error-estimates default_required]
A differential tells us which input errors matter most near the point. The coefficient
      of dx measures sensitivity to x. The coefficient of dy measures
      sensitivity to y. The coefficient of dz measures sensitivity to z.

[324-324 title c7s4-subsec-differentials-as-1-forms default_required]
Differentials as the first examples of 1-forms

[326-331 p c7s4-subsec-differentials-as-1-forms default_required]
The expression
      df=f_x\,dx+f_y\,dy
      is a special kind of object. It is a rule that assigns, at each point, a linear function of
      small displacements.

[333-333 p c7s4-subsec-differentials-as-1-forms default_required]
That is exactly the concrete meaning of a 1-form.

[336-336 title checkpoint-7-4-df-as-a-machine default_required]
What does df eat, and what does it return?

[338-344 p checkpoint-7-4-df-as-a-machine default_required]
People often call a 1-form like df a machine: feed it a direction (a small
          displacement) at a point and it hands back a single number. Using
          df_{(2,1)}=2\,dx-2\,dy as your example, say in plain words what you must supply to the
          machine and what it gives you back. In what sense is df therefore a different kind of object
          than the function f itself?

[347-351 p checkpoint-7-4-df-as-a-machine hint]
The function f eats a point and returns a value; df at a point eats a
          direction and returns a rate of change. Notice that dx and dy are themselves
          such machines, they just read off one component of the displacement you feed in.

[356-356 title c7s4-def-1-form-in-the-plane default_required]
1-form in the plane

[358-367 p c7s4-def-1-form-in-the-plane default_required]
A 1-form on a region D\subseteq\mathbb R^2 is an expression
          \boxed{ \omega=P(x,y)\,dx+Q(x,y)\,dy. }
          At a point
          \mathbf p=(x,y),
          it acts on a displacement
          \Delta\mathbf x=(\Delta x,\Delta y)
          by
          \boxed{ \omega_{\mathbf p}(\Delta\mathbf x) = P(x,y)\Delta x+Q(x,y)\Delta y. }

[371-376 p c7s4-subsec-differentials-as-1-forms default_required]
In space, a 1-form has the form
      \boxed{ \omega=P(x,y,z)\,dx+Q(x,y,z)\,dy+R(x,y,z)\,dz, }
      and
      \boxed{ \omega_{\mathbf p}(\Delta x,\Delta y,\Delta z) = P(\mathbf p)\Delta x+Q(\mathbf p)\Delta y+R(\mathbf p)\Delta z. }

[378-386 p c7s4-subsec-differentials-as-1-forms default_required]
A differential
      df
      is a 1-form:
      \boxed{ df=f_x\,dx+f_y\,dy }
      in the plane, and
      \boxed{ df=f_x\,dx+f_y\,dy+f_z\,dz }
      in space.

[389-389 title c7s4-def-exact-1-form default_required]
Exact 1-form

[391-395 p c7s4-def-exact-1-form default_required]
A 1-form \omega is called exact if there is a function
          f such that
          \omega=df.

[399-412 p c7s4-subsec-differentials-as-1-forms default_required]
For example,
      \omega=2x\,dx+2y\,dy
      is exact, because
      \omega=d(x^2+y^2).
      But a general 1-form need not come from a function. The swirling form
      \omega=-y\,dx+x\,dy
      is built from the vector field
      \mathbf W(x,y)=(-y,x).
      At each point it measures how much a small displacement points with the swirl:
      \omega_{(x,y)}(\Delta x,\Delta y) = -y\Delta x+x\Delta y.
      Whether such a form is a differential of some scalar field is a separate question. We
      will need line integrals and curl before we can answer it well.

[414-418 p c7s4-subsec-differentials-as-1-forms default_required]
For now, df is the bridge between ordinary functions and 1-forms. A function
      has values. Its differential measures first-order change. A 1-form is ready to be
      added along a curve.

[420-430 p c7s4-subsec-differentials-as-1-forms default_required]
There is one more piece in this chapter before curves return. A scalar function has one
      differential:
      df.
      A transformation
      F=(F_1,F_2,\ldots,F_m)
      has one differential for each component:
      dF_1,\quad dF_2,\quad \ldots,\quad dF_m.
      Stacking these linear functions into rows gives the matrix of the total derivative. That
      matrix is the Jacobian, and it tells how a nonlinear map moves small grids near a point.
