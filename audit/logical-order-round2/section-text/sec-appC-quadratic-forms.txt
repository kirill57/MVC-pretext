[5-5 title sec-appC-quadratic-forms default_required]
Quadratic forms

[8-8 title appC-qf-definition default_required]
Definition

[10-10 p appC-qf-definition default_required]
A quadratic form is a function built from degree-two terms.

[12-15 p appC-qf-definition default_required]
In matrix form:
      \boxed{q(\mathbf x)=\mathbf x^T A\mathbf x.}

[17-17 p appC-qf-definition default_required]
Usually A is taken to be symmetric.

[21-21 title appC-qf-two-variable-form default_required]
Two-variable form

[23-48 p appC-qf-two-variable-form default_required]
For
      
        \mathbf x=
        \begin{pmatrix}
        x\\
        y
        \end{pmatrix},
      
      and
      
        A=
        \begin{pmatrix}
        a&b\\
        b&c
        \end{pmatrix},
      
      we get
      
        \boxed{
        \mathbf x^T A\mathbf x
        =
        ax^2+2bxy+cy^2.
        }

[50-62 p appC-qf-two-variable-form default_required]
So the form
      ax^2+2bxy+cy^2
      corresponds to the matrix
      
        \boxed{
        \begin{pmatrix}
        a&b\\
        b&c
        \end{pmatrix}.
        }

[66-66 title appC-qf-symmetric-part default_required]
Symmetric part

[68-77 p appC-qf-symmetric-part default_required]
For any square matrix A,
      
        \boxed{
        \mathbf x^T A\mathbf x
        =
        \mathbf x^T\left(\frac{A+A^T}{2}\right)\mathbf x.
        }

[79-79 p appC-qf-symmetric-part default_required]
So only the symmetric part of A matters for a quadratic form.

[83-83 title appC-qf-positive-definite default_required]
Positive definite

[85-93 p appC-qf-positive-definite default_required]
A quadratic form is positive definite if
      
        \boxed{
        q(\mathbf x)\gt 0
        \quad\text{for every }\mathbf x\ne\mathbf 0.
        }

[95-103 p appC-qf-positive-definite default_required]
A symmetric matrix A is positive definite if
      
        \boxed{
        \mathbf x^T A\mathbf x\gt 0
        \quad\text{for every }\mathbf x\ne\mathbf 0.
        }

[107-107 title appC-qf-negative-definite default_required]
Negative definite

[109-117 p appC-qf-negative-definite default_required]
A quadratic form is negative definite if
      
        \boxed{
        q(\mathbf x)\lt 0
        \quad\text{for every }\mathbf x\ne\mathbf 0.
        }

[121-121 title appC-qf-indefinite default_required]
Indefinite

[123-123 p appC-qf-indefinite default_required]
A quadratic form is indefinite if it takes both positive and negative values.

[125-134 p appC-qf-indefinite default_required]
\boxed{
        q(\mathbf u)\gt 0
        \quad\text{and}\quad
        q(\mathbf v)\lt 0
        }
      
      for some vectors \mathbf u,\mathbf v.

[138-138 title appC-qf-semidefinite default_required]
Semidefinite

[140-148 p appC-qf-semidefinite default_required]
Positive semidefinite:
      
        \boxed{
        q(\mathbf x)\ge0
        \quad\text{for every }\mathbf x.
        }

[150-158 p appC-qf-semidefinite default_required]
Negative semidefinite:
      
        \boxed{
        q(\mathbf x)\le0
        \quad\text{for every }\mathbf x.
        }

[160-160 p appC-qf-semidefinite default_required]
Semidefinite forms can be zero on nonzero vectors.

[243-243 title appC-qf-diagonalization default_required]
Diagonalization of a quadratic form

[245-249 p appC-qf-diagonalization default_required]
If A is symmetric, then
      \boxed{A=QDQ^T,}
      where Q is orthogonal and D is diagonal.

[251-264 p appC-qf-diagonalization default_required]
Let
      \mathbf y=Q^T\mathbf x.
      Then
      
        \boxed{
        \mathbf x^T A\mathbf x
        =
        \mathbf y^T D\mathbf y
        =
        \lambda_1 y_1^2+\cdots+\lambda_n y_n^2.
        }

[266-268 p appC-qf-diagonalization default_required]
The eigenvalues are the coefficients along the orthogonal principal directions.
      The second derivative of q in the corresponding unit direction is
      2\lambda_i.

[272-272 title appC-qf-connection-to-hessians default_required]
Connection to Hessians

[274-285 p appC-qf-connection-to-hessians default_required]
For a function f(x,y), the Hessian matrix is
      
        \boxed{
        H_f=
        \begin{pmatrix}
        f_{xx} & f_{xy}\\
        f_{yx} & f_{yy}
        \end{pmatrix}.
        }

[287-291 p appC-qf-connection-to-hessians default_required]
When mixed partials agree,
      f_{xy}=f_{yx},
      so H_f is symmetric.

[293-304 p appC-qf-connection-to-hessians default_required]
Near a critical point \mathbf p, the quadratic approximation is
      
        \boxed{
        f(\mathbf p+\mathbf h)
        \approx
        f(\mathbf p)
        +
        \frac12\mathbf h^T H_f(\mathbf p)\mathbf h.
        }

[354-354 title appC-qf-common-warnings default_required]
Common warnings

[357-360 p appC-qf-warning-zero-determinant default_required]
A zero determinant in the Hessian test does not mean there is no maximum or minimum.
        It means the quadratic test does not decide.

[364-381 p appC-qf-warning-symmetric-matrix default_required]
The matrix for
        ax^2+bxy+cy^2
        is
        
          \begin{pmatrix}
          a & b/2\\
          b/2 & c
          \end{pmatrix},
        
        not
        
          \begin{pmatrix}
          a & b\\
          b & c
          \end{pmatrix}.

[382-386 p appC-qf-warning-symmetric-matrix default_required]
The form
        \mathbf x^T A\mathbf x
        uses a symmetric matrix when reading geometry.
