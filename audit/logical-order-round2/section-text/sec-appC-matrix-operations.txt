[5-5 title sec-appC-matrix-operations default_required]
Matrix operations

[8-8 title appC-ops-matrix-notation default_required]
Matrix notation

[10-23 p appC-ops-matrix-notation default_required]
An m\times n matrix has m rows and n columns:
      
        \boxed{
        A=
        \begin{pmatrix}
        a_{11} \amp a_{12} \amp \cdots \amp a_{1n}\\
        a_{21} \amp a_{22} \amp \cdots \amp a_{2n}\\
        \vdots \amp \vdots \amp \ddots \amp \vdots\\
        a_{m1} \amp a_{m2} \amp \cdots \amp a_{mn}
        \end{pmatrix}.
        }

[25-32 p appC-ops-matrix-notation default_required]
The entry in row i, column j is
      
        \boxed{
        a_{ij}.
        }

[34-47 p appC-ops-matrix-notation default_required]
A column vector in \mathbb R^n is an n\times1 matrix:
      
        \boxed{
        \mathbf x=
        \begin{pmatrix}
        x_1\\
        x_2\\
        \vdots\\
        x_n
        \end{pmatrix}.
        }

[51-51 title appC-ops-addition default_required]
Addition

[53-53 p appC-ops-addition default_required]
Matrices can be added only when they have the same size.

[55-61 p appC-ops-addition default_required]
\boxed{
        (A+B)_{ij}=a_{ij}+b_{ij}.
        }

[65-65 title appC-ops-scalar-multiplication default_required]
Scalar multiplication

[67-73 p appC-ops-scalar-multiplication default_required]
\boxed{
        (cA)_{ij}=c\,a_{ij}.
        }

[77-77 title appC-ops-matrix-vector-multiplication default_required]
Matrix-vector multiplication

[79-86 p appC-ops-matrix-vector-multiplication default_required]
If A is m\times n and \mathbf x\in\mathbb R^n, then
      
        \boxed{
        A\mathbf x\in\mathbb R^m.
        }

[88-97 p appC-ops-matrix-vector-multiplication default_required]
The ith component is
      
        \boxed{
        (A\mathbf x)_i
        =
        a_{i1}x_1+a_{i2}x_2+\cdots+a_{in}x_n.
        }

[99-109 p appC-ops-matrix-vector-multiplication default_required]
Equivalently,
      
        \boxed{
        A\mathbf x
        =
        x_1\mathbf a_1+x_2\mathbf a_2+\cdots+x_n\mathbf a_n,
        }
      
      where \mathbf a_1,\ldots,\mathbf a_n are the columns of A.

[113-113 title appC-ops-matrix-multiplication default_required]
Matrix multiplication

[115-122 p appC-ops-matrix-multiplication default_required]
If A is m\times n and B is n\times p, then
      
        \boxed{
        AB\text{ is }m\times p.
        }

[124-133 p appC-ops-matrix-multiplication default_required]
The entry in row i, column j is
      
        \boxed{
        (AB)_{ij}
        =
        \sum_{k=1}^{n}a_{ik}b_{kj}.
        }

[135-142 p appC-ops-matrix-multiplication default_required]
Matrix multiplication means composition of linear maps:
      
        \boxed{
        A(B\mathbf x)=(AB)\mathbf x.
        }

[146-146 title appC-ops-identity-matrix default_required]
Identity matrix

[148-161 p appC-ops-identity-matrix default_required]
The n\times n identity matrix is
      
        \boxed{
        I_n=
        \begin{pmatrix}
        1\amp0\amp\cdots\amp0\\
        0\amp1\amp\cdots\amp0\\
        \vdots\amp\vdots\amp\ddots\amp\vdots\\
        0\amp0\amp\cdots\amp1
        \end{pmatrix}.
        }

[163-170 p appC-ops-identity-matrix default_required]
It satisfies
      
        \boxed{
        I_n\mathbf x=\mathbf x.
        }

[172-179 p appC-ops-identity-matrix default_required]
If the sizes match,
      
        \boxed{
        AI=IA=A.
        }

[183-183 title appC-ops-zero-matrix default_required]
Zero matrix

[185-192 p appC-ops-zero-matrix default_required]
The zero matrix has all entries equal to 0. It satisfies
      
        \boxed{
        A+0=A.
        }

[194-203 p appC-ops-zero-matrix default_required]
If the sizes match,
      
        \boxed{
        A0=0,
        \qquad
        0A=0.
        }

[207-207 title appC-ops-transpose default_required]
Transpose

[209-209 p appC-ops-transpose default_required]
The transpose of A is A^T. Rows become columns.

[211-217 p appC-ops-transpose default_required]
\boxed{
        (A^T)_{ij}=a_{ji}.
        }

[219-241 p appC-ops-transpose default_required]
Rules:
      
        \boxed{
        (A+B)^T=A^T+B^T
        }
      
      
        \boxed{
        (cA)^T=cA^T
        }
      
      
        \boxed{
        (AB)^T=B^T A^T
        }
      
      
        \boxed{
        (A^T)^T=A.
        }

[245-245 title appC-ops-symmetric-matrix default_required]
Symmetric matrix

[247-254 p appC-ops-symmetric-matrix default_required]
A square matrix is symmetric if
      
        \boxed{
        A^T=A.
        }

[256-256 p appC-ops-symmetric-matrix default_required]
Symmetric matrices are especially important for Hessians and quadratic forms.

[260-260 title appC-ops-common-warnings default_required]
Common warnings

[263-271 p appC-ops-warning-noncommutative default_required]
Matrix multiplication is usually not commutative:
        
          \boxed{
          AB\ne BA
          \quad\text{in general}.
          }

[273-273 p appC-ops-warning-noncommutative default_required]
The product AB may exist even when BA does not.

[275-275 p appC-ops-warning-noncommutative default_required]
If both AB and BA exist, they may have different sizes.

[277-277 p appC-ops-warning-noncommutative default_required]
Always check dimensions before multiplying.
