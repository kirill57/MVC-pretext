[5-5 title sec-appC-determinants default_required]
Determinants

[6-6 p sec-appC-determinants default_required]
The arbitrary-size determinant is defined by the permutation formula in . The formulas below specialize it to dimensions two and three and collect its consequences.

[9-9 title appC-det-only-square-matrices default_required]
Only square matrices have determinants

[11-20 p appC-det-only-square-matrices default_required]
The determinant is defined for square matrices:
      
        \boxed{
        A\text{ is }n\times n
        \quad\Longrightarrow\quad
        \det A\text{ is a number}.
        }

[24-24 title appC-det-2x2-determinant default_required]
2\times2 determinant

[26-38 p appC-det-2x2-determinant default_required]
\boxed{
        \det
        \begin{pmatrix}
        a \amp b\\
        c \amp d
        \end{pmatrix}
        =
        ad-bc.
        }

[40-40 p appC-det-2x2-determinant default_required]
Geometric meaning:

[42-50 p appC-det-2x2-determinant default_required]
\boxed{
        |\det A|
        =
        \text{area scale factor of the linear map }A.
        }

[52-52 p appC-det-2x2-determinant default_required]
The sign records orientation.

[56-56 title appC-det-3x3-determinant default_required]
3\times3 determinant

[58-71 p appC-det-3x3-determinant default_required]
\boxed{
        \det
        \begin{pmatrix}
        a \amp b \amp c\\
        d \amp e \amp f\\
        g \amp h \amp i
        \end{pmatrix}
        =
        a(ei-fh)-b(di-fg)+c(dh-eg).
        }

[73-73 p appC-det-3x3-determinant default_required]
Geometric meaning:

[75-83 p appC-det-3x3-determinant default_required]
\boxed{
        |\det A|
        =
        \text{volume scale factor of the linear map }A.
        }

[85-85 p appC-det-3x3-determinant default_required]
The sign records orientation.

[89-89 title appC-det-determinant-and-orientation default_required]
Determinant and orientation

[91-98 p appC-det-determinant-and-orientation default_required]
\boxed{
        \det A\gt 0
        }
      
      means orientation is preserved.

[100-107 p appC-det-determinant-and-orientation default_required]
\boxed{
        \det A\lt 0
        }
      
      means orientation is reversed.

[109-116 p appC-det-determinant-and-orientation default_required]
\boxed{
        \det A=0
        }
      
      means area or volume collapses.

[120-120 title appC-det-singular-matrices default_required]
Singular matrices

[122-130 p appC-det-singular-matrices default_required]
For a square matrix A,
      
        \boxed{
        \det A=0
        }
      
      means A is singular.

[132-132 p appC-det-singular-matrices default_required]
Equivalently, the linear map collapses some nonzero direction to zero.

[136-136 title appC-det-determinant-properties default_required]
Determinant properties

[138-144 p appC-det-determinant-properties default_required]
\boxed{
        \det(I)=1
        }

[146-152 p appC-det-determinant-properties default_required]
\boxed{
        \det(A^T)=\det(A)
        }

[154-160 p appC-det-determinant-properties default_required]
\boxed{
        \det(AB)=\det(A)\det(B)
        }

[162-169 p appC-det-determinant-properties default_required]
If A is invertible,
      
        \boxed{
        \det(A^{-1})=\frac1{\det(A)}.
        }

[171-178 p appC-det-determinant-properties default_required]
If A is triangular, then
      
        \boxed{
        \det(A)=\text{product of diagonal entries}.
        }

[182-182 title appC-det-effect-of-row-operations default_required]
Effect of row operations

[184-184 p appC-det-effect-of-row-operations default_required]
Swapping two rows changes the sign of the determinant.

[186-186 p appC-det-effect-of-row-operations default_required]
Multiplying one row by c multiplies the determinant by c.

[188-188 p appC-det-effect-of-row-operations default_required]
Adding a multiple of one row to another row does not change the determinant.

[192-192 title appC-det-determinant-and-linear-independence default_required]
Determinant and linear independence

[194-202 p appC-det-determinant-and-linear-independence default_required]
For an n\times n matrix A,
      
        \boxed{
        \det A\ne0
        }
      
      if and only if the columns of A are linearly independent.

[204-211 p appC-det-determinant-and-linear-independence default_required]
\boxed{
        \det A=0
        }
      
      if and only if the columns of A are linearly dependent.

[215-215 title appC-det-determinant-and-change-of-variables default_required]
Determinant and change of variables

[217-234 p appC-det-determinant-and-change-of-variables default_required]
For a coordinate map
      
        (u,v)\mapsto (x(u,v),y(u,v)),
      
      the Jacobian determinant is
      
        \boxed{
        \frac{\partial(x,y)}{\partial(u,v)}
        =
        \det
        \begin{pmatrix}
        x_u \amp x_v\\
        y_u \amp y_v
        \end{pmatrix}.
        }

[236-248 p appC-det-determinant-and-change-of-variables default_required]
For ordinary area,
      
        \boxed{
        dA
        =
        \left|
        \frac{\partial(x,y)}{\partial(u,v)}
        \right|
        \,du\,dv.
        }

[250-260 p appC-det-determinant-and-change-of-variables default_required]
For oriented area,
      
        \boxed{
        dx\wedge dy
        =
        \frac{\partial(x,y)}{\partial(u,v)}
        \,du\wedge dv.
        }

[264-264 title appC-det-common-warnings default_required]
Common warnings

[266-272 p appC-det-common-warnings default_required]
The determinant is not linear in the whole matrix:
      
        \det(A+B)\ne\det(A)+\det(B)
      
      in general.

[274-274 p appC-det-common-warnings default_required]
A determinant can be negative. Ordinary area and volume use |\det A|.

[276-276 p appC-det-common-warnings default_required]
If row reduction uses row swaps or row scaling, track how the determinant changes.
