[45-53 p c13s8-skills default_required]
For a parametrized curve
      \mathbf r(t)=(x(t),y(t),z(t)), \qquad a\le t\le b,
      the scalar line integral is
      \boxed{ \int_C f\,ds = \int_a^b f(\mathbf r(t))\|\mathbf r'(t)\|\,dt. }
      The speed
      \|\mathbf r'(t)\|
      turns parameter time into arc length.

[55-63 p c13s8-skills default_required]
For a 1-form
      \omega=P\,dx+Q\,dy+R\,dz,
      the line integral is
      \boxed{ \int_C \omega = \int_a^b \left[ P(\mathbf r(t))x'(t) + Q(\mathbf r(t))y'(t) + R(\mathbf r(t))z'(t) \right]dt. }
      Here
      dx=x'(t)\,dt,\qquad dy=y'(t)\,dt,\qquad dz=z'(t)\,dt.
      No norm appears. Orientation survives.

[99-105 p c13s8-skills default_required]
The exact case is the easiest case, once we recognize it. If
      \omega=d\phi,
      then
      \boxed{ \int_C \omega=\phi(B)-\phi(A), }
      where A is the starting point and B is the ending point.

[107-107 p c13s8-skills default_required]
This is the Fundamental Theorem of Calculus in curve form.

[110-110 title c13s8-worked-review default_required]
A final worked review problem

[112-122 p c13s8-worked-review default_required]
Let
        \omega=(2xy+z)\,dx+(x^2+3z)\,dy+(x+3y)\,dz.
        Find
        \int_C \omega
        along any path from
        A=(0,0,1)
        to
        B=(2,1,3),
        if the integral is path independent.

[124-149 p c13s8-worked-review default_required]
First look for a potential \phi. If
        \omega=d\phi,
        then
        \phi_x=2xy+z.
        Integrate with respect to x:
        \phi=x^2y+xz+g(y,z).
        Now differentiate this with respect to y:
        \phi_y=x^2+g_y(y,z).
        We need
        \phi_y=x^2+3z,
        so
        g_y=3z.
        Thus
        g(y,z)=3yz+h(z).
        Now
        \phi=x^2y+xz+3yz+h(z).
        Differentiate with respect to z:
        \phi_z=x+3y+h'(z).
        We need
        \phi_z=x+3y.
        So
        h'(z)=0.
        One potential is
        \boxed{ \phi(x,y,z)=x^2y+xz+3yz. }

[151-163 p c13s8-worked-review default_required]
Therefore
        
          \int_C \omega \amp = \phi(B)-\phi(A)
          \amp = \phi(2,1,3)-\phi(0,0,1)
          \amp = (2^2\cdot1+2\cdot3+3\cdot1\cdot3)-0
          \amp = 4+6+9
          \amp = 19.
        
        So
        \boxed{ \int_C \omega=19. }
        No parametrization of C was needed.

[167-167 title c13s8-exterior-derivative-thread default_required]
The exterior derivative thread

[169-169 p c13s8-exterior-derivative-thread default_required]
This chapter also prepared the next step in the differential-forms story.

[171-175 p c13s8-exterior-derivative-thread default_required]
A function is a 0-form. Its exterior derivative is
        d\phi=\phi_x\,dx+\phi_y\,dy+\phi_z\,dz.
        This is the 1-form version of the gradient.

[177-185 p c13s8-exterior-derivative-thread default_required]
For a plane C^1 1-form
        \omega=P\,dx+Q\,dy,
        we now define its exterior derivative in this case by
        \boxed{ d\omega=(Q_x-P_y)\,dx\wedge dy. }
        The coefficient
        Q_x-P_y
        is the scalar curl.

[187-199 p c13s8-exterior-derivative-thread default_required]
So the plane curl test
        Q_x-P_y=0
        can be written as
        d\omega=0.
        If \phi has continuous second partial derivatives, its exact form satisfies
        \omega=d\phi,
        and the definition gives
        d\omega=(\phi_{yx}-\phi_{xy})\,dx\wedge dy=0
        by equality of mixed partials from .
        This proves the local, planar instance of the rule
        \boxed{ d^2=0. }

[204-204 title c13s8-project default_required]
Project: work done in a nonconservative field

[206-215 p c13s8-project default_required]
The field
      \mathbf F(x,y)=(-y,x)
      is the simplest rotational field. Its work form is
      \eta=-y\,dx+x\,dy.
      It is not conservative, because
      Q_x-P_y=1-(-1)=2.
      So a particle can return to where it started and still have nonzero total work done by
      the field.

[217-217 p c13s8-project default_required]
This project reveals a pattern that is too beautiful to be accidental.

[220-220 title c13s8-project-rectangle default_required]
A rectangle

[222-227 p c13s8-project-rectangle default_required]
Let R be the rectangle
        0\le x\le a, \qquad 0\le y\le b.
        Orient its boundary counterclockwise. That means the rectangle stays on your left as
        you walk around it.

[229-232 p c13s8-project-rectangle default_required]
Compute
        \oint_{\partial R} -y\,dx+x\,dy.

[234-234 p c13s8-project-rectangle default_required]
There are four sides.

[236-241 p c13s8-project-rectangle default_required]
On the bottom side,
        y=0,\qquad dy=0,
        so
        -y\,dx+x\,dy=0.

[243-250 p c13s8-project-rectangle default_required]
On the right side,
        x=a,\qquad dx=0,\qquad 0\le y\le b,
        so
        -y\,dx+x\,dy=a\,dy.
        The contribution is
        \int_0^b a\,dy=ab.

[252-259 p c13s8-project-rectangle default_required]
On the top side,
        y=b,\qquad dy=0,
        and the path goes from x=a to x=0. The form becomes
        -b\,dx.
        The contribution is
        \int_a^0 -b\,dx=ab.

[261-266 p c13s8-project-rectangle default_required]
On the left side,
        x=0,\qquad dx=0,
        so
        -y\,dx+x\,dy=0.

[268-275 p c13s8-project-rectangle default_required]
Adding the four sides,
        \boxed{ \oint_{\partial R} -y\,dx+x\,dy=2ab. }
        But
        ab=\operatorname{Area}(R).
        So
        \boxed{ \oint_{\partial R} -y\,dx+x\,dy = 2\,\operatorname{Area}(R). }

[312-315 p c13s8-project-rectangle default_required]
The coefficient 2 is not a coincidence. It is the scalar curl:
        Q_x-P_y=2.

[317-321 p c13s8-project-rectangle default_required]
So the rectangle calculation says
        \boxed{ \oint_{\partial R}\eta = \iint_R 2\,dA. }
        The left side is a boundary integral. The right side is an area integral over the region.

[325-325 title c13s8-project-circle default_required]
A circle

[327-343 p c13s8-project-circle default_required]
For a circle of radius R, use
        \mathbf r(t)=(R\cos t,R\sin t), \qquad 0\le t\le2\pi.
        Then
        dx=-R\sin t\,dt, \qquad dy=R\cos t\,dt.
        So
        
          -y\,dx+x\,dy \amp = -(R\sin t)(-R\sin t\,dt) + (R\cos t)(R\cos t\,dt)
          \amp = R^2\,dt.
        
        Thus
        \boxed{ \oint_C -y\,dx+x\,dy = \int_0^{2\pi}R^2\,dt = 2\pi R^2. }
        But the area of the disk is
        \pi R^2.
        Again,
        \boxed{ \oint_C -y\,dx+x\,dy = 2\,\operatorname{Area}(\text{disk}). }

[347-347 title c13s8-project-polygon default_required]
A polygon and the shoelace formula

[349-370 p c13s8-project-polygon default_required]
Try the same integral around a polygon with vertices
        (x_1,y_1),(x_2,y_2),\ldots,(x_n,y_n),
        listed counterclockwise, with
        (x_{n+1},y_{n+1})=(x_1,y_1).
        On the straight edge from (x_i,y_i) to (x_{i+1},y_{i+1}), a parametrization is
        x(t)=x_i+t(x_{i+1}-x_i),
        y(t)=y_i+t(y_{i+1}-y_i), \qquad 0\le t\le1.
        Then
        dx=(x_{i+1}-x_i)\,dt, \qquad dy=(y_{i+1}-y_i)\,dt.
        Substitution gives
        -y\,dx+x\,dy = \bigl(x_i y_{i+1}-x_{i+1}y_i\bigr)\,dt.
        So the edge contribution is
        x_i y_{i+1}-x_{i+1}y_i.
        Adding all edges,
        \boxed{ \oint_{\partial P}-y\,dx+x\,dy = \sum_{i=1}^n \bigl(x_i y_{i+1}-x_{i+1}y_i\bigr). }
        This suggests the shoelace area formula
        \boxed{ \operatorname{Area}(P) = \frac12 \sum_{i=1}^n \bigl(x_i y_{i+1}-x_{i+1}y_i\bigr) }
        for a simple counterclockwise polygon. We will prove it from Green's theorem in
        . Once established, it gives
        \boxed{ \oint_{\partial P}-y\,dx+x\,dy = 2\,\operatorname{Area}(P). }

[372-375 p c13s8-project-polygon default_required]
The rotational field has become an area-measuring device. By doing work only around
        the boundary, it finds the area inside.

[377-377 p c13s8-project-polygon default_required]
That is the surprise Green's theorem will explain.

[382-382 title c13s8-hook default_required]
Hook: circulation becomes a two-dimensional integral

[384-387 p c13s8-hook default_required]
The rectangle, circle, and polygon computations all point to the same hidden rule: a
      boundary integral can equal an interior integral.

[389-400 p c13s8-hook default_required]
For
      \eta=-y\,dx+x\,dy,
      we found
      d\eta=2\,dx\wedge dy.
      The boundary integral measured
      \oint_{\partial R}\eta,
      while the interior integral measured
      \iint_R d\eta = \iint_R 2\,dx\wedge dy.
      For the rectangle and circle we have proved directly that
      \boxed{ \oint_{\partial R}\eta = \iint_R d\eta. }

[402-408 p c13s8-hook default_required]
The next chapter shows that this is not a trick of one special field. For a large class
      of regions R and 1-forms
      \omega=P\,dx+Q\,dy,
      Green's theorem says
      \boxed{ \oint_{\partial R} \omega = \iint_R d\omega = \iint_R (Q_x-P_y)\,dx\wedge dy. }

[410-413 p c13s8-hook default_required]
The curl that was only a test in this chapter becomes something we can add over an area.
      A curve around the boundary will know what happened throughout the region inside it.
