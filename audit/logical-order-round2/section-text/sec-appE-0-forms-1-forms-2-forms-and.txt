[5-5 title sec-appE-0-forms-1-forms-2-forms-and default_required]
0-forms, 1-forms, 2-forms, and 3-forms

[8-8 title subsec-appE-forms-0-forms default_required]
0-forms

[10-13 p subsec-appE-forms-0-forms default_required]
A 0-form is a function:
      \boxed{ f. }

[15-18 p subsec-appE-forms-0-forms default_required]
Examples:
      f(x), \qquad f(x,y), \qquad f(x,y,z).

[20-23 p subsec-appE-forms-0-forms default_required]
A 0-form is integrated over signed points:
      \boxed{ \int_{+P}f=f(P), \qquad \int_{-P}f=-f(P). }

[25-28 p subsec-appE-forms-0-forms default_required]
For an oriented interval,
      \boxed{ \partial[a,b]=\{b\}-\{a\}. }

[30-33 p subsec-appE-forms-0-forms default_required]
So
      \boxed{ \int_{\partial[a,b]}f=f(b)-f(a). }

[37-37 title subsec-appE-forms-1-forms default_required]
1-forms

[39-42 p subsec-appE-forms-1-forms default_required]
A 1-form in the plane has the form
      \boxed{ \omega=P(x,y)\,dx+Q(x,y)\,dy. }

[44-47 p subsec-appE-forms-1-forms default_required]
A 1-form in space has the form
      \boxed{ \omega=P(x,y,z)\,dx+Q(x,y,z)\,dy+R(x,y,z)\,dz. }

[49-49 p subsec-appE-forms-1-forms default_required]
It is integrated over oriented curves.

[51-56 p subsec-appE-forms-1-forms default_required]
If
      \mathbf F=(P,Q,R),
      then the work 1-form is
      \boxed{ \omega_{\mathbf F}=P\,dx+Q\,dy+R\,dz. }

[58-61 p subsec-appE-forms-1-forms default_required]
Line integral:
      \boxed{ \int_C \mathbf F\cdot d\mathbf r = \int_C \omega_{\mathbf F}. }

[65-65 title subsec-appE-forms-2-forms-plane default_required]
2-forms in the plane

[67-70 p subsec-appE-forms-2-forms-plane default_required]
A 2-form in the plane has the form
      \boxed{ \alpha=f(x,y)\,dx\wedge dy. }

[72-72 p subsec-appE-forms-2-forms-plane default_required]
It is integrated over oriented plane regions.

[74-78 p subsec-appE-forms-2-forms-plane default_required]
The form
      \boxed{ dx\wedge dy }
      measures signed area.

[80-83 p subsec-appE-forms-2-forms-plane default_required]
\boxed{ \iint_R f\,dx\wedge dy }
      means signed accumulation of f over R.

[85-92 p subsec-appE-forms-2-forms-plane default_required]
For ordinary unsigned area of the parallelogram spanned by \mathbf u,\mathbf v,
      take the absolute value of the measurement:
      \boxed{|(dx\wedge dy)(\mathbf u,\mathbf v)|.}
      For integration with Cartesian coordinates, we write
      \boxed{ dA=dx\,dy }
      for positive area.

[96-96 title subsec-appE-forms-2-forms-space default_required]
2-forms in space

[98-101 p subsec-appE-forms-2-forms-space default_required]
A general 2-form in space can be written as
      \boxed{ \Phi = A\,dy\wedge dz + B\,dz\wedge dx + C\,dx\wedge dy. }

[103-103 p subsec-appE-forms-2-forms-space default_required]
This ordering matches flux.

[105-110 p subsec-appE-forms-2-forms-space default_required]
If
      \mathbf F=(P,Q,R),
      the flux 2-form is
      \boxed{ \Phi_{\mathbf F} = P\,dy\wedge dz + Q\,dz\wedge dx + R\,dx\wedge dy. }

[112-115 p subsec-appE-forms-2-forms-space default_required]
Flux integral:
      \boxed{ \iint_S \mathbf F\cdot\widehat{\mathbf n}\,dS = \iint_S \Phi_{\mathbf F}. }

[119-119 title subsec-appE-forms-3-forms default_required]
3-forms

[121-124 p subsec-appE-forms-3-forms default_required]
A 3-form in space has the form
      \boxed{ \Omega=f(x,y,z)\,dx\wedge dy\wedge dz. }

[126-126 p subsec-appE-forms-3-forms default_required]
It is integrated over oriented solids.

[128-132 p subsec-appE-forms-3-forms default_required]
The form
      \boxed{ dx\wedge dy\wedge dz }
      measures signed volume.

[134-138 p subsec-appE-forms-3-forms default_required]
For ordinary volume,
      \boxed{ dV=dx\,dy\,dz }
      in the usual orientation.

[142-142 title subsec-appE-forms-degree default_required]
Degree

[144-144 p subsec-appE-forms-degree default_required]
The degree of a form is the number of differentials wedged together.

[174-174 title subsec-appE-forms-common-warnings default_required]
Common warnings

[178-181 p warn-appE-forms-common default_required]
A 1-form is not a vector field, though a vector field can produce a
          1-form.

[182-185 p warn-appE-forms-common default_required]
A 2-form is not a vector field, though a vector field can produce a flux
          2-form.

[186-188 p warn-appE-forms-common default_required]
Forms remember orientation. Reversing orientation changes the sign of the integral.
