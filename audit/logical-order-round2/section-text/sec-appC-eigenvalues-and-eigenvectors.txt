[5-5 title sec-appC-eigenvalues-and-eigenvectors default_required]
Eigenvalues and eigenvectors

[8-8 title appC-eig-definition default_required]
Definition

[10-10 p appC-eig-definition default_required]
Let A be an n\times n matrix.

[12-20 p appC-eig-definition default_required]
A nonzero vector \mathbf v is an eigenvector of A if
      
        \boxed{
        A\mathbf v=\lambda \mathbf v
        }
      
      for some scalar \lambda.

[22-22 p appC-eig-definition default_required]
The scalar \lambda is the eigenvalue.

[26-26 title appC-eig-meaning default_required]
Meaning

[28-28 p appC-eig-meaning default_required]
An eigenvector is a direction that A does not turn.

[30-30 p appC-eig-meaning default_required]
The matrix A only stretches, shrinks, or reverses that direction.

[32-42 p appC-eig-meaning default_required]
\begin{array}{c|c}
        \lambda \amp \text{Effect on eigenvector direction} \\ \hline
        \lambda\gt1 \amp \text{stretch}\\
        0\lt\lambda\lt1 \amp \text{shrink}\\
        \lambda\lt0 \amp \text{reverse direction and scale}\\
        \lambda=0 \amp \text{collapse to zero}
        \end{array}

[46-46 title appC-eig-finding-eigenvalues default_required]
Finding eigenvalues

[48-63 p appC-eig-finding-eigenvalues default_required]
Start with
      
        A\mathbf v=\lambda\mathbf v.
      
      Rewrite:
      
        (A-\lambda I)\mathbf v=\mathbf 0.
      
      For a nonzero solution \mathbf v, the matrix A-\lambda I must be singular:
      
        \boxed{
        \det(A-\lambda I)=0.
        }

[65-65 p appC-eig-finding-eigenvalues default_required]
This equation is the characteristic equation.

[69-69 title appC-eig-characteristic-polynomial default_required]
Characteristic polynomial

[71-77 p appC-eig-characteristic-polynomial default_required]
\boxed{
        p(\lambda)=\det(A-\lambda I).
        }

[79-86 p appC-eig-characteristic-polynomial default_required]
Eigenvalues are the roots of
      
        \boxed{
        p(\lambda)=0.
        }

[90-90 title appC-eig-2x2-shortcut default_required]
2\times2 shortcut

[92-113 p appC-eig-2x2-shortcut default_required]
If
      
        A=
        \begin{pmatrix}
        a\amp b\\
        c\amp d
        \end{pmatrix},
      
      then
      
        \boxed{
        \operatorname{tr}(A)=a+d
        }
      
      and
      
        \boxed{
        \det(A)=ad-bc.
        }

[115-122 p appC-eig-2x2-shortcut default_required]
The characteristic equation can be written as
      
        \boxed{
        \lambda^2-\operatorname{tr}(A)\lambda+\det(A)=0.
        }

[126-126 title appC-eig-finding-eigenvectors default_required]
Finding eigenvectors

[128-135 p appC-eig-finding-eigenvectors default_required]
For each eigenvalue \lambda, solve
      
        \boxed{
        (A-\lambda I)\mathbf v=\mathbf 0.
        }

[137-137 p appC-eig-finding-eigenvectors default_required]
The solution space is the eigenspace for \lambda.

[139-145 p appC-eig-finding-eigenvectors default_required]
\boxed{
        E_\lambda=\operatorname{Null}(A-\lambda I).
        }

[147-155 p appC-eig-finding-eigenvectors default_required]
Remember:
      
        \boxed{
        \mathbf v\ne\mathbf 0.
        }
      
      The zero vector is never called an eigenvector.

[159-159 title appC-eig-diagonal-matrices default_required]
Diagonal matrices

[161-178 p appC-eig-diagonal-matrices default_required]
If
      
        D=
        \begin{pmatrix}
        \lambda_1\amp0\amp\cdots\amp0\\
        0\amp\lambda_2\amp\cdots\amp0\\
        \vdots\amp\vdots\amp\ddots\amp\vdots\\
        0\amp0\amp\cdots\amp\lambda_n
        \end{pmatrix},
      
      then the standard basis vectors are eigenvectors:
      
        \boxed{
        D\mathbf e_i=\lambda_i\mathbf e_i.
        }

[182-182 title appC-eig-diagonalization default_required]
Diagonalization

[184-200 p appC-eig-diagonalization default_required]
If A has n linearly independent eigenvectors
      
        \mathbf v_1,\ldots,\mathbf v_n,
      
      then put them into a matrix
      
        \boxed{
        P=
        \begin{pmatrix}
        |\amp|\amp\amp|\\
        \mathbf v_1\amp\mathbf v_2\amp\cdots\amp\mathbf v_n\\
        |\amp|\amp\amp|
        \end{pmatrix}.
        }

[202-215 p appC-eig-diagonalization default_required]
Let
      
        \boxed{
        D=
        \begin{pmatrix}
        \lambda_1\amp0\amp\cdots\amp0\\
        0\amp\lambda_2\amp\cdots\amp0\\
        \vdots\amp\vdots\amp\ddots\amp\vdots\\
        0\amp0\amp\cdots\amp\lambda_n
        \end{pmatrix}.
        }

[217-224 p appC-eig-diagonalization default_required]
Then
      
        \boxed{
        A=PDP^{-1}.
        }

[228-228 title appC-eig-powers default_required]
Powers

[230-241 p appC-eig-powers default_required]
If
      
        A=PDP^{-1},
      
      then
      
        \boxed{
        A^k=PD^kP^{-1}.
        }

[243-256 p appC-eig-powers default_required]
For a diagonal matrix,
      
        \boxed{
        D^k=
        \begin{pmatrix}
        \lambda_1^k\amp0\amp\cdots\amp0\\
        0\amp\lambda_2^k\amp\cdots\amp0\\
        \vdots\amp\vdots\amp\ddots\amp\vdots\\
        0\amp0\amp\cdots\amp\lambda_n^k
        \end{pmatrix}.
        }

[260-260 title appC-eig-symmetric-matrices default_required]
Symmetric matrices

[262-275 p appC-eig-symmetric-matrices default_required]
If
      
        A^T=A,
      
      then:
      
        \begin{array}{ll}
        1. \amp \text{All eigenvalues of }A\text{ are real.}\\[1mm]
        2. \amp \text{Eigenvectors for different eigenvalues are orthogonal.}\\[1mm]
        3. \amp A\text{ has an orthonormal eigenbasis.}
        \end{array}

[277-290 p appC-eig-symmetric-matrices default_required]
Thus a symmetric matrix can be written as
      
        \boxed{
        A=QDQ^T,
        }
      
      where Q is orthogonal:
      
        \boxed{
        Q^TQ=I.
        }

[292-295 p appC-eig-symmetric-matrices default_required]
Symmetric matrices are the clean case. Hessian matrices are symmetric when mixed
      partials agree.

[299-299 title appC-eig-common-warnings default_required]
Common warnings

[302-302 p appC-eig-warning-common default_required]
Eigenvectors must be nonzero.

[304-304 p appC-eig-warning-common default_required]
Eigenvalues can be repeated.

[306-306 p appC-eig-warning-common default_required]
A matrix may fail to have enough eigenvectors to diagonalize.

[308-308 p appC-eig-warning-common default_required]
Eigenvalues are defined only for square matrices.

[310-310 p appC-eig-warning-common default_required]
For real matrices, complex eigenvalues may occur unless the matrix is symmetric.
