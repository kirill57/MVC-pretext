[5-5 title sec-3-linear-functions-r-n-r default_required]
Linear functions \mathbb R^n\to\mathbb R

[7-14 p sec-3-linear-functions-r-n-r default_required]
Recall from Chapter 2 that
    dx(x,y)=x,\qquad dy(x,y)=y,
    and in space,
    dz(x,y,z)=z.
    Each of these rules measures one part of a vector. If we double the vector, the
    measurement doubles. If we add two vectors, the measurements add.

[16-16 p sec-3-linear-functions-r-n-r default_required]
That is the behavior we now want to name.

[19-19 title c3s1-subsec-steady-ramp default_required]
A steady ramp

[21-24 p c3s1-subsec-steady-ramp default_required]
Imagine a flat metal ramp in a warehouse. Moving one meter east raises you 3 cm.
      Moving one meter north raises you 2 cm.

[26-34 p c3s1-subsec-steady-ramp default_required]
If your displacement along the floor is
      \mathbf v=(x,y),
      then your change in height is
      L(x,y)=3x+2y.
      For example,
      L(4,-1)=3\cdot4+2(-1)=10.
      So moving 4 meters east and 1 meter south raises you 10 cm.

[36-36 p c3s1-subsec-steady-ramp default_required]
This rule has two very natural properties.

[38-49 p c3s1-subsec-steady-ramp default_required]
First, if you break a trip into two pieces,
      \mathbf u=(x_1,y_1), \qquad \mathbf v=(x_2,y_2),
      then
      
        L(\mathbf u+\mathbf v) \amp= L(x_1+x_2,y_1+y_2)
        \amp= 3(x_1+x_2)+2(y_1+y_2)
        \amp= (3x_1+2y_1)+(3x_2+2y_2)
        \amp= L(\mathbf u)+L(\mathbf v).
      
      The height gained on the whole trip is the sum of the height gains on the pieces.

[51-60 p c3s1-subsec-steady-ramp default_required]
Second, if you stretch a displacement by a factor c, the height change stretches by
      the same factor:
      
        L(c\mathbf u) \amp= L(cx_1,cy_1)
        \amp= 3cx_1+2cy_1
        \amp= c(3x_1+2y_1)
        \amp= cL(\mathbf u).

[62-62 p c3s1-subsec-steady-ramp default_required]
These two properties are what linearity means.

[65-65 title c3s1-def-linear-function default_required]
Linear function

[67-75 p c3s1-def-linear-function default_required]
A function
          \ell:\mathbb R^n\to\mathbb R
          is called linear if, for all vectors \mathbf u,\mathbf v\in\mathbb R^n
          and all scalars c,
          \ell(\mathbf u+\mathbf v)=\ell(\mathbf u)+\ell(\mathbf v),
          and
          \ell(c\mathbf u)=c\ell(\mathbf u).

[79-84 p c3s1-subsec-steady-ramp default_required]
The two rules can be combined. If \ell is linear, then
      \ell(a\mathbf u+b\mathbf v) = a\ell(\mathbf u)+b\ell(\mathbf v).
      More generally,
      \ell(c_1\mathbf v_1+\cdots+c_k\mathbf v_k) = c_1\ell(\mathbf v_1)+\cdots+c_k\ell(\mathbf v_k).

[86-91 p c3s1-subsec-steady-ramp default_required]
A linear function must also send the zero vector to zero:
      \ell(\mathbf 0)=0.
      Indeed,
      \ell(\mathbf 0)=\ell(0\mathbf u)=0\ell(\mathbf u)=0.

[93-93 p c3s1-subsec-steady-ramp default_required]
This small fact is a useful warning.

[96-96 title c3s1-ex-almost-linear default_required]
A rule that is almost linear but not linear

[98-107 p c3s1-ex-almost-linear default_required]
The rule
          A(x,y)=3x+2y+10
          looks very much like the ramp rule, but it is not linear. It does not send the zero
          vector to zero:
          A(0,0)=10.
          It describes a flat ramp whose height at the origin is already 10 cm. Such rules are
          called affine. They will matter later, especially for tangent planes. But they
          are not linear.

[112-112 title c3s1-ex-rule-that-bends default_required]
A rule that bends

[114-122 p c3s1-ex-rule-that-bends default_required]
The rule
          Q(x,y)=x^2+y
          is not linear. For instance,
          Q(2,0)=4,
          but
          2Q(1,0)=2.
          Doubling the input did not double the output. The square term bends the rule.

[126-126 p c3s1-subsec-steady-ramp default_required]
Linear functions are the rules that do not bend and do not shift the origin.

[130-130 title c3s1-subsec-values-on-basis default_required]
Values on basis vectors determine the whole function

[132-147 p c3s1-subsec-values-on-basis default_required]
The ramp rule
      L(x,y)=3x+2y
      is completely determined by what it does to the two standard basis vectors:
      \mathbf e_1=(1,0), \qquad \mathbf e_2=(0,1).
      Indeed,
      L(\mathbf e_1)=3, \qquad L(\mathbf e_2)=2.
      Since every vector in \mathbb R^2 can be written as
      (x,y)=x\mathbf e_1+y\mathbf e_2,
      linearity forces
      
        L(x,y) \amp= L(x\mathbf e_1+y\mathbf e_2)
        \amp= xL(\mathbf e_1)+yL(\mathbf e_2)
        \amp= 3x+2y.

[149-153 p c3s1-subsec-values-on-basis default_required]
So once we know the two numbers
      L(\mathbf e_1),\qquad L(\mathbf e_2),
      we know L everywhere.

[155-155 p c3s1-subsec-values-on-basis default_required]
The same idea works in every dimension.

[158-158 title checkpoint-3-1-basis-determines default_required]
Why do the basis values decide everything?

[160-164 p checkpoint-3-1-basis-determines default_required]
Suppose you only know the numbers \ell(\mathbf e_1),\ldots,\ell(\mathbf e_n) for a linear
          function \ell:\mathbb R^n\to\mathbb R. Explain in your own words why this is already enough
          to compute \ell(\mathbf x) for any vector \mathbf x, with no further information needed.

[167-170 p checkpoint-3-1-basis-determines hint]
Write \mathbf x in terms of the basis vectors, then ask which property of \ell lets you
          push \ell through that sum.

[175-175 title c3s1-thm-determined-by-basis default_required]
A linear function is determined by its values on the standard basis

[177-186 p c3s1-thm-determined-by-basis default_required]
Let
          \ell:\mathbb R^n\to\mathbb R
          be linear. If
          \mathbf e_1,\mathbf e_2,\ldots,\mathbf e_n
          are the standard basis vectors, then every vector
          \mathbf x=(x_1,x_2,\ldots,x_n)
          satisfies
          \boxed{ \ell(\mathbf x) = x_1\ell(\mathbf e_1)+x_2\ell(\mathbf e_2)+\cdots+x_n\ell(\mathbf e_n). }

[191-199 p c3s1-subsec-values-on-basis default_required]
Every vector in \mathbb R^n can be written as
        \mathbf x=x_1\mathbf e_1+x_2\mathbf e_2+\cdots+x_n\mathbf e_n.
        Using linearity,
        
          \ell(\mathbf x) \amp= \ell(x_1\mathbf e_1+x_2\mathbf e_2+\cdots+x_n\mathbf e_n)
          \amp= x_1\ell(\mathbf e_1)+x_2\ell(\mathbf e_2)+\cdots+x_n\ell(\mathbf e_n).

[202-205 p c3s1-subsec-values-on-basis default_required]
This theorem is one of the main reasons basis vectors are useful. To understand a
      linear rule, we do not have to test every vector. We only test the basic directions.

[209-209 title c3s1-subsec-dot-products default_required]
Linear functions as dot products with fixed vectors

[211-222 p c3s1-subsec-dot-products default_required]
Suppose a small cart moves through space by
      \mathbf x=(x,y,z)
      meters, and a constant force
      \mathbf F=(6,-2,4)
      newtons acts on it. The work done by the force is
      W(x,y,z)=6x-2y+4z.
      This is a linear function:
      W:\mathbb R^3\to\mathbb R.
      It is also a dot product:
      W(\mathbf x)=\mathbf F\cdot\mathbf x.

[224-227 p c3s1-subsec-dot-products default_required]
This was the first physical reason for the dot product in Chapter 2. Now it becomes a
      general algebraic fact: every linear function is a dot product with one fixed vector.

[230-230 title checkpoint-3-1-why-dot-product default_required]
Why must a linear function be a dot product?

[232-235 p checkpoint-3-1-why-dot-product default_required]
Take any linear function \ell:\mathbb R^n\to\mathbb R. Where would the components of the
          fixed vector \mathbf a have to come from, and why is there no freedom in choosing them?

[238-241 p checkpoint-3-1-why-dot-product hint]
Feed the basis vectors into \ell one at a time. What does \mathbf a\cdot\mathbf e_j have
          to equal?

[245-248 p c3s1-subsec-dot-products default_required]
For vectors in \mathbb R^n, we use the same dot product formula:
      \mathbf a\cdot\mathbf x = a_1x_1+a_2x_2+\cdots+a_nx_n.

[251-251 title c3s1-thm-every-linear-is-dot-product default_required]
Every linear function is a dot product

[253-261 p c3s1-thm-every-linear-is-dot-product default_required]
Let
          \ell:\mathbb R^n\to\mathbb R
          be linear. Then there is a unique vector
          \mathbf a=(a_1,a_2,\ldots,a_n)
          such that
          \boxed{ \ell(\mathbf x)=\mathbf a\cdot\mathbf x }
          for every \mathbf x\in\mathbb R^n.

[262-265 p c3s1-thm-every-linear-is-dot-product default_required]
The vector is
          \boxed{ \mathbf a= \bigl(\ell(\mathbf e_1),\ell(\mathbf e_2),\ldots,\ell(\mathbf e_n)\bigr). }

[270-281 p c3s1-subsec-dot-products default_required]
Set
        a_1=\ell(\mathbf e_1),\quad a_2=\ell(\mathbf e_2),\quad \ldots,\quad a_n=\ell(\mathbf e_n).
        For
        \mathbf x=(x_1,\ldots,x_n),
        the previous theorem gives
        
          \ell(\mathbf x) \amp= x_1\ell(\mathbf e_1)+\cdots+x_n\ell(\mathbf e_n)
          \amp= a_1x_1+\cdots+a_nx_n
          \amp= \mathbf a\cdot\mathbf x.

[282-285 p c3s1-subsec-dot-products default_required]
The vector \mathbf a is unique because its components are forced:
        a_j=\mathbf a\cdot\mathbf e_j=\ell(\mathbf e_j).

[289-289 title c3s1-ex-finding-fixed-vector default_required]
Finding the fixed vector

[291-300 p c3s1-ex-finding-fixed-vector default_required]
Let
          \ell:\mathbb R^3\to\mathbb R
          be linear, and suppose
          \ell(\mathbf e_1)=5,\qquad \ell(\mathbf e_2)=-1,\qquad \ell(\mathbf e_3)=4.
          Then
          \ell(x,y,z)=5x-y+4z.
          Equivalently,
          \ell(\mathbf x)=(5,-1,4)\cdot\mathbf x.

[301-304 p c3s1-ex-finding-fixed-vector default_required]
For example,
          \ell(2,3,-1) = 5\cdot2-3+4(-1) = 3.

[308-313 p c3s1-subsec-dot-products default_required]
The fixed vector
      \mathbf a
      is the coefficient vector of the linear function. It tells us how strongly the function
      measures each coordinate direction.

[317-317 title c3s1-subsec-level-sets default_required]
Level sets of linear functions

[319-325 p c3s1-subsec-level-sets default_required]
Return to the ramp
      L(x,y)=3x+2y.
      The set of all displacements that produce height change 12 cm is
      3x+2y=12.
      This is a line.

[327-332 p c3s1-subsec-level-sets default_required]
The set of all displacements that produce height change 0 is
      3x+2y=0.
      This is the line of level motion along the ramp. Walking in such a direction does not
      raise or lower you.

[335-335 title checkpoint-3-1-parallel-hyperplanes default_required]
Why are the level sets parallel?

[337-342 p checkpoint-3-1-parallel-hyperplanes default_required]
The level sets \mathbf a\cdot\mathbf x=c for different values of c never tilt relative to
          one another; they stay parallel. Using only the dot product, explain why two points on the
          same level set always differ by a vector perpendicular to \mathbf a, and why that
          forces every level set to share the same direction.

[345-348 p checkpoint-3-1-parallel-hyperplanes hint]
Subtract the two equations \mathbf a\cdot\mathbf p=c and \mathbf a\cdot\mathbf q=c. The
          direction \mathbf a does not depend on c.

[353-354 caption c3s1-fig-level-sets default_required]
The level sets of L(x,y)=3x+2y are parallel lines. The vector (3,2)
      is perpendicular to them.

[356-370 latex-image c3s1-fig-level-sets default_required]
\begin{tikzpicture}[scale=0.65, >=stealth]
            \draw[->] (-4.5,0) -- (5.5,0) node[right] {\(x\)};
            \draw[->] (0,-4.5) -- (0,5.5) node[above] {\(y\)};

            \foreach \c/\lab in {-12/{-12}, -6/{-6}, 0/{0}, 6/{6}, 12/{12}} {
                \draw[thick] (-4,{(\c-3*(-4))/2}) -- (5,{(\c-3*5)/2});
                \node[fill=white, inner sep=1pt] at (4.3,{(\c-3*4.3)/2}) {\(\lab\)};
            }

            \draw[->, very thick] (0,0) -- (3,2) node[above right] {\((3,2)\)};
            \node at (-2.9,4.4) {\(3x+2y=c\)};
            \node[below right] at (0,0) {\(0\)};
        \end{tikzpicture}

[374-384 p c3s1-subsec-level-sets default_required]
The coefficient vector
      \mathbf a=(3,2)
      is perpendicular to these level lines. To see why, take two points \mathbf p and
      \mathbf q on the same level set:
      \mathbf a\cdot\mathbf p=c, \qquad \mathbf a\cdot\mathbf q=c.
      Subtract:
      \mathbf a\cdot(\mathbf p-\mathbf q)=0.
      So every displacement \mathbf p-\mathbf q along the level set is orthogonal to
      \mathbf a.

[386-394 p c3s1-subsec-level-sets default_required]
The same idea works in space. A linear function
      \ell(x,y,z)=ax+by+cz
      has level sets
      ax+by+cz=d.
      When (a,b,c)\neq(0,0,0), these are planes. The vector
      (a,b,c)
      is normal to the planes.

[397-397 title c3s1-thm-level-sets-nonzero default_required]
Level sets of a nonzero linear function

[399-410 p c3s1-thm-level-sets-nonzero default_required]
Let
          \ell(\mathbf x)=\mathbf a\cdot\mathbf x
          be a linear function on \mathbb R^n, with
          \mathbf a\neq\mathbf 0.
          For each number c, the level set
          \ell(\mathbf x)=c
          is an affine hyperplane. Its direction vectors are precisely the vectors
          \mathbf w
          that satisfy
          \mathbf a\cdot\mathbf w=0.

[415-421 p c3s1-subsec-level-sets default_required]
Because \mathbf a\neq\mathbf 0, the point
        \mathbf p=\frac{c}{\|\mathbf a\|^2}\mathbf a
        satisfies
        \mathbf a\cdot\mathbf p = \mathbf a\cdot\left(\frac{c}{\|\mathbf a\|^2}\mathbf a\right) = \frac{c}{\|\mathbf a\|^2}(\mathbf a\cdot\mathbf a) = c.
        So the level set is not empty.

[422-433 p c3s1-subsec-level-sets default_required]
Now a point \mathbf x lies on the same level set exactly when
        \mathbf a\cdot\mathbf x=c.
        Since
        \mathbf a\cdot\mathbf p=c,
        this is equivalent to
        \mathbf a\cdot(\mathbf x-\mathbf p)=0.
        Thus
        \mathbf x=\mathbf p+\mathbf w, \qquad \text{where } \mathbf a\cdot\mathbf w=0.
        That is an affine hyperplane through \mathbf p, with direction space perpendicular
        to \mathbf a.

[436-448 p c3s1-subsec-level-sets default_required]
The hypothesis
      \mathbf a\neq\mathbf 0
      is necessary. If
      \mathbf a=\mathbf 0,
      then
      \ell(\mathbf x)=0
      for every \mathbf x. The level set
      \ell(\mathbf x)=0
      is all of \mathbb R^n, not a hyperplane. And the level set
      \ell(\mathbf x)=5
      is empty.

[450-455 p c3s1-subsec-level-sets default_required]
So a nonzero coefficient vector is what gives a genuine linear equation:
      a_1x_1+a_2x_2+\cdots+a_nx_n=c.
      In two dimensions this equation describes a line. In three dimensions it describes a
      plane. In \mathbb R^n it describes a hyperplane.

[457-464 p c3s1-subsec-level-sets default_required]
A linear function measures one number from a vector. But many real machines do more
      than measure one number. A camera turns a point in space into two screen coordinates.
      A robot command turns a joystick displacement into a new displacement. A grid can be
      stretched, sheared, rotated, or projected. Each output coordinate is a linear function,
      and when we stack those coordinate measurements together, a new object appears:
      a linear transformation.
