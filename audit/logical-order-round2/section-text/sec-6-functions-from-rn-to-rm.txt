[5-5 title sec-6-functions-from-rn-to-rm default_required]
Functions from \mathbb R^n to \mathbb R^m

[7-14 p sec-6-functions-from-rn-to-rm default_required]
followed a moving point:
    \mathbf r(t).
    The input was time, and the output was a vector. Now the input will often be a point
    in the plane or in space. A room temperature depends on where you stand. A pressure
    inside a tank depends on position. A wind velocity assigns an arrow to each point on a
    map.

[16-19 p sec-6-functions-from-rn-to-rm default_required]
The word function stays the same. What changes is the shape of the input and
    the shape of the output.

[22-22 title c6s1-subsec-temperature-field-room-floor default_required]
A temperature field on a room floor

[24-35 p c6s1-subsec-temperature-field-room-floor default_required]
Picture a rectangular room. The floor coordinates are measured in meters, with
      0\le x\le 6, \qquad 0\le y\le 4.
      A heater sits near (2,1), and a cold window runs along the north wall. A simple
      model for the temperature on the floor is
      T(x,y)=20+\frac{6}{1+(x-2)^2+(y-1)^2}-\frac{y}{2}.
      The input is a point
      (x,y)
      on the floor. The output is one number,
      T(x,y),
      the temperature in degrees Celsius.

[37-42 p c6s1-subsec-temperature-field-room-floor default_required]
At the heater location,
      T(2,1)=20+\frac{6}{1+0+0}-\frac12=25.5.
      Near the far cold corner,
      T(5,4)=20+\frac{6}{1+9+9}-2=18+\frac{6}{19}\approx 18.32.

[44-47 p c6s1-subsec-temperature-field-room-floor default_required]
So T takes a point in the floor and returns a number. That is a scalar-valued
      function of two variables.

[50-51 caption c6s1-fig-temperature-field default_required]
A scalar-valued function can assign one number, such as temperature, to each
      point in a region.

[77-87 p c6s1-subsec-temperature-field-room-floor default_required]
The same input region could also carry arrows. Suppose the air in the room slowly
      circulates around a ceiling fan. A simple two-dimensional model for the horizontal air
      velocity is
      \mathbf W(x,y)=\left(-\frac{y-2}{5},\frac{x-3}{5}\right).
      At the point (3,0),
      \mathbf W(3,0)=\left(\frac25,0\right),
      so the air is moving to the right. At the point (6,2),
      \mathbf W(6,2)=\left(0,\frac35\right),
      so the air is moving upward.

[89-92 p c6s1-subsec-temperature-field-room-floor default_required]
Now the input is still a point (x,y), but the output is a vector. This is a
      vector-valued function of two variables.

[95-95 title c6s1-def-function-rn-rm default_required]
Function from \mathbb R^n to \mathbb R^m

[97-104 p c6s1-def-function-rn-rm default_required]
A function
          F:D\subseteq \mathbb R^n\to \mathbb R^m
          assigns to each input
          \mathbf x\in D
          exactly one output
          F(\mathbf x)\in \mathbb R^m.

[105-108 p c6s1-def-function-rn-rm default_required]
The set D is called the domain. The set of all possible outputs
          is called the range.

[112-115 p c6s1-subsec-temperature-field-room-floor default_required]
If m=1, the output is a number. We call the function scalar-valued.
      If m>1, the output is a vector. We call the function vector-valued.

[118-118 title c6s1-def-scalar-vector-field default_required]
Scalar field and vector field

[120-123 p c6s1-def-scalar-vector-field default_required]
A scalar-valued function on a region in the plane or in space is often called a
          scalar field.

[124-127 p c6s1-def-scalar-vector-field default_required]
A vector-valued function on a region in the plane or in space is often called a
          vector field.

[131-134 p c6s1-subsec-temperature-field-room-floor default_required]
A temperature field is a scalar field. A wind field is a vector field. Later, line
      integrals and surface integrals will live inside this language.

[194-196 p c6s1-subsec-scalar-vector-valued default_required]
The notation F:D\subseteq\mathbb R^n\to\mathbb R^m records the actual domain D, which may be a smaller region of input space. Writing simply F:\mathbb R^n\to\mathbb R^m specifies all of \mathbb R^n as the domain. A formula and a model may have different domains, so state the restriction when it matters.

[198-204 p c6s1-subsec-scalar-vector-valued default_required]
For example, the temperature model above is not meant for all of \mathbb R^2.
      It is meant for the rectangle
      D=\{(x,y):0\le x\le 6,\ 0\le y\le 4\}.
      Outside the room, the formula may still produce a number, but the model no longer
      describes the room.

[207-207 title c6s1-ex-vector-valued-from-ch5 default_required]
A vector-valued function from

[209-216 p c6s1-ex-vector-valued-from-ch5 default_required]
The helix
          \mathbf r(t)=(2\cos t,2\sin t,t)
          is a function
          \mathbf r:\mathbb R\to\mathbb R^3.
          It has one input and three output components. It is vector-valued, but it is not a
          function of several variables. The input is still one-dimensional.

[221-221 title c6s1-ex-parametrized-surface default_required]
A parametrized surface

[223-230 p c6s1-ex-parametrized-surface default_required]
A circular cylinder of radius 2 can be parametrized by
          \mathbf s(\theta,z)=(2\cos\theta,2\sin\theta,z).
          Here
          \mathbf s:\mathbb R^2\to\mathbb R^3.
          The input has two variables, \theta and z. The output is a point in
          space.

[231-236 p c6s1-ex-parametrized-surface default_required]
If we restrict
          0\le \theta\le 2\pi,\qquad 0\le z\le 5,
          then the domain is a rectangle in the (\theta,z)-plane, and the image is the
          side of a cylinder of height 5.

[240-244 p c6s1-subsec-scalar-vector-valued default_required]
The same notation covers scalar fields, vector fields, motion, and parametrized
      surfaces. The input dimension tells us how many independent variables we choose.
      The output dimension tells us what kind of object the function returns.

[247-247 title checkpoint-6-1-scalar-vs-vector-output default_required]
Scalar or vector?

[249-254 p checkpoint-6-1-scalar-vs-vector-output default_required]
Two functions can both take a point of the plane as input, yet feel completely
          different. What single feature of the output tells you whether a function is
          a scalar field or a vector field, and why does it matter that the output of a vector
          field carries more than one number?

[257-260 p checkpoint-6-1-scalar-vs-vector-output hint]
Look at m in F:\mathbb R^n\to\mathbb R^m. Ask what you would draw at a
          single point in each case: a temperature reading, or an arrow with a direction.

[266-266 title c6s1-subsec-domains-plane-space default_required]
Domains in the plane and in space

[268-271 p c6s1-subsec-domains-plane-space default_required]
Sometimes a domain comes from a physical situation. Sometimes it comes from the
      formula itself.

[274-274 title c6s1-ex-dome-circular-floor default_required]
A dome over a circular floor

[276-286 p c6s1-ex-dome-circular-floor default_required]
A glass dome over a circular courtyard has height
          h(x,y)=\sqrt{16-x^2-y^2}.
          The square root requires
          16-x^2-y^2\ge 0.
          Therefore
          x^2+y^2\le 16.
          The natural domain is the disk
          D=\{(x,y):x^2+y^2\le 16\}.
          The formula describes the upper half of a sphere of radius 4.

[291-291 title c6s1-ex-missing-plane default_required]
A formula with a missing plane

[293-302 p c6s1-ex-missing-plane default_required]
Let
          g(x,y,z)=\frac{1}{z-y}.
          The denominator cannot be zero, so
          z-y\ne0.
          The domain is
          D=\{(x,y,z):z\ne y\}.
          This is all of space except the plane
          z=y.

[307-307 title c6s1-ex-logarithm-in-space default_required]
A logarithm in space

[309-318 p c6s1-ex-logarithm-in-space default_required]
Let
          q(x,y,z)=\ln(8-z).
          The logarithm requires
          8-z>0,
          so
          z<8.
          The domain is the open half-space below the plane z=8:
          D=\{(x,y,z):z<8\}.

[323-323 title c6s1-ex-swirling-field-missing-point default_required]
A swirling field with a missing point

[325-334 p c6s1-ex-swirling-field-missing-point default_required]
The vector field
          \mathbf V(x,y)=\frac{1}{x^2+y^2}(-y,x)
          is defined whenever
          x^2+y^2\ne0.
          So its domain is
          \mathbb R^2\setminus\{(0,0)\}.
          The origin is missing. This small hole will matter later: fields defined on regions
          with holes can behave in surprising ways.

[338-341 p c6s1-subsec-domains-plane-space default_required]
The word domain is therefore not a decoration. It is part of the function.
      Changing the domain can change the meaning of the problem.

[344-344 title checkpoint-6-1-domain-dimension-matters default_required]
Why count the inputs?

[346-350 p checkpoint-6-1-domain-dimension-matters default_required]
Suppose two friends both write down the rule z\mapsto z, but one is thinking of
          a function on the line and the other of a function on space. Why can the dimension of
          the domain change the meaning of a function just as much as the rule itself does?

[353-357 p checkpoint-6-1-domain-dimension-matters hint]
Think about how many independent variables you are free to vary, and what region the
          inputs sweep out. The same algebraic expression can live over a line, a plane, or all
          of space.

[363-363 title c6s1-subsec-examples-temperature-pressure-cost-motion default_required]
Examples from temperature, pressure, cost, and motion

[365-365 p c6s1-subsec-examples-temperature-pressure-cost-motion default_required]
A function of several variables often begins as a story before it becomes a formula.

[368-368 title c6s1-ex-pressure-in-tank default_required]
Pressure in a tank

[370-376 p c6s1-ex-pressure-in-tank default_required]
Suppose z measures height in meters, and pressure decreases linearly as height
          increases:
          p(x,y,z)=120-3z.
          This is a scalar field in space. It does not depend on x or y, only on
          height. All points with the same z-coordinate have the same pressure.

[381-381 title c6s1-ex-cost-function-two-inputs default_required]
A cost function with two inputs

[383-390 p c6s1-ex-cost-function-two-inputs default_required]
A bakery makes two kinds of loaves. Let u be the number of sourdough loaves
          and v the number of rye loaves made in one day. A simplified cost model is
          C(u,v)=400+3u+4v+0.01uv.
          The term 400 is a fixed daily cost. The terms 3u and 4v are
          direct production costs. The mixed term 0.01uv models the extra scheduling
          cost of producing both types in the same day.

[391-397 p c6s1-ex-cost-function-two-inputs default_required]
The physical domain is
          u\ge0,\qquad v\ge0.
          Strictly speaking, u and v should be whole numbers. Calculus treats
          them as continuous variables because that approximation lets us study rates of
          change.

[402-402 title c6s1-ex-deformation-of-plane default_required]
A deformation of the plane

[404-410 p c6s1-ex-deformation-of-plane default_required]
A flexible sheet is pulled so that each point (x,y) moves to
          F(x,y)=(x+0.2y,\ y).
          This is a vector-valued function
          F:\mathbb R^2\to\mathbb R^2.
          It shears the plane: points higher up move farther to the right.

[411-415 p c6s1-ex-deformation-of-plane default_required]
This example is also a linear transformation, so it belongs to . The new
          point is that transformations are functions too. They take points or vectors as
          inputs and return points or vectors as outputs.

[421-421 title c6s1-subsec-functions-as-fields-of-values default_required]
Functions as fields of values

[423-425 p c6s1-subsec-functions-as-fields-of-values default_required]
A scalar field covers a region with numbers. A vector field covers a region with arrows.

[428-428 title checkpoint-6-1-picture-as-field default_required]
Why picture a field?

[430-434 p checkpoint-6-1-picture-as-field default_required]
A formula like \mathbf W(x,y)=(-y,x) already gives every value exactly. So why
          is it still useful to imagine the function as a whole field of values spread across
          its domain, rather than as one input-output computation at a time?

[437-440 p checkpoint-6-1-picture-as-field hint]
A single value tells you about one point. A field lets you see how the values change
          from place to place, so patterns like swirling or flowing become visible at a glance.

[444-452 p c6s1-subsec-functions-as-fields-of-values default_required]
For example, the vector field
      \mathbf W(x,y)=(-y,x)
      assigns an arrow to every point in the plane. At (1,0),
      \mathbf W(1,0)=(0,1).
      At (0,1),
      \mathbf W(0,1)=(-1,0).
      The arrows circulate counterclockwise around the origin.
