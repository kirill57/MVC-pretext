[5-5 title sec-appC-inverse-matrices default_required]
Inverse matrices

[8-8 title appC-inv-definition default_required]
Definition

[10-17 p appC-inv-definition default_required]
A square matrix A is invertible if there is a matrix A^{-1} such that
      
        \boxed{
        A^{-1}A=AA^{-1}=I.
        }

[19-21 p appC-inv-definition default_required]
The matrix A^{-1} is the inverse of A.

[25-25 title appC-inv-meaning default_required]
Meaning

[27-38 p appC-inv-meaning default_required]
If
      
        \mathbf y=A\mathbf x,
      
      then
      
        \boxed{
        \mathbf x=A^{-1}\mathbf y.
        }

[40-42 p appC-inv-meaning default_required]
The inverse matrix undoes the linear map A.

[46-46 title appC-inv-two-by-two-formula default_required]
2\times2 inverse formula

[48-75 p appC-inv-two-by-two-formula default_required]
If
      
        A=
        \begin{pmatrix}
        a&b\\
        c&d
        \end{pmatrix},
      
      then
      
        \boxed{
        A^{-1}
        =
        \frac{1}{ad-bc}
        \begin{pmatrix}
        d&-b\\
        -c&a
        \end{pmatrix}
        }
      
      provided
      
        \boxed{
        ad-bc\ne0.
        }

[79-79 title appC-inv-invertibility-test default_required]
Invertibility test

[81-83 p appC-inv-invertibility-test default_required]
For an n\times n matrix A, the following statements are equivalent:

[85-97 p appC-inv-invertibility-test default_required]
\begin{array}{ll}
        1. & A\text{ is invertible.}\\[1mm]
        2. & \det A\ne0.\\[1mm]
        3. & A\mathbf x=\mathbf 0\text{ has only the trivial solution.}\\[1mm]
        4. & A\mathbf x=\mathbf b\text{ has a unique solution for every }\mathbf b.\\[1mm]
        5. & \text{The columns of }A\text{ are linearly independent.}\\[1mm]
        6. & \text{The columns of }A\text{ span }\mathbb R^n.\\[1mm]
        7. & \operatorname{rref}(A)=I.
        \end{array}

[101-101 title appC-inv-by-row-reduction default_required]
Finding an inverse by row reduction

[103-110 p appC-inv-by-row-reduction default_required]
To find A^{-1}, row reduce
      
        \boxed{
        [A\mid I].
        }

[112-125 p appC-inv-by-row-reduction default_required]
If
      
        [A\mid I]
        \longrightarrow
        [I\mid B],
      
      then
      
        \boxed{
        B=A^{-1}.
        }

[127-129 p appC-inv-by-row-reduction default_required]
If the left side cannot be reduced to I, then A is not invertible.

[133-133 title appC-inv-solving-systems default_required]
Solving systems with inverses

[135-144 p appC-inv-solving-systems default_required]
If A is invertible, then
      
        \boxed{
        A\mathbf x=\mathbf b
        \quad\Longrightarrow\quad
        \mathbf x=A^{-1}\mathbf b.
        }

[148-148 title appC-inv-rules default_required]
Inverse rules

[150-173 p appC-inv-rules default_required]
If A and B are invertible, then
      
        \boxed{
        (AB)^{-1}=B^{-1}A^{-1}.
        }
      
      
        \boxed{
        (A^{-1})^{-1}=A.
        }
      
      
        \boxed{
        (A^T)^{-1}=(A^{-1})^T.
        }
      
      
        \boxed{
        (cA)^{-1}=\frac1c A^{-1}
        \qquad (c\ne0).
        }

[177-177 title appC-inv-common-warnings default_required]
Common warnings

[180-185 p appC-inv-warning-common default_required]
The inverse of a product reverses the order:
        
          (AB)^{-1}=B^{-1}A^{-1}.

[187-189 p appC-inv-warning-common default_required]
Not every square matrix has an inverse.

[191-193 p appC-inv-warning-common default_required]
Non-square matrices do not have two-sided inverses.

[195-198 p appC-inv-warning-common default_required]
In practice, row reduction is usually better than explicitly computing A^{-1} to
        solve a system.
