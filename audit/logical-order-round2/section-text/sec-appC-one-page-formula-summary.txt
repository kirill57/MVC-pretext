One-page formula summary

[6-6 p sec-appC-one-page-formula-summary default_required]
Determinant and inverse formulas concern square matrices. The final Hessian test assumes f is C^2 near the critical point being tested.

[8-21 p sec-appC-one-page-formula-summary default_required]
\boxed{(A\mathbf x)_i = \sum_{j=1}^n a_{ij}x_j}
      \boxed{(AB)_{ij} = \sum_k a_{ik}b_{kj}}
      \boxed{(AB)^T=B^T A^T}
      \boxed{\det \begin{pmatrix} a\amp b\\ c\amp d \end{pmatrix} = ad-bc}
      \boxed{\det(AB)=\det(A)\det(B)}
      \boxed{A^{-1} = \frac{1}{ad-bc} \begin{pmatrix} d\amp -b\\ -c\amp a \end{pmatrix}}
    
    for
    
      A= \begin{pmatrix} a\amp b\\ c\amp d \end{pmatrix}, \qquad ad-bc\ne0.

[23-31 p sec-appC-one-page-formula-summary default_required]
\boxed{A\text{ invertible} \Longleftrightarrow \det A\ne0}
      \boxed{A\mathbf v=\lambda\mathbf v}
      \boxed{\det(A-\lambda I)=0}
      \boxed{A=PDP^{-1}}
    
    when A has enough independent eigenvectors.

[33-41 p sec-appC-one-page-formula-summary default_required]
\boxed{q(\mathbf x)=\mathbf x^T A\mathbf x}
      \boxed{ax^2+2bxy+cy^2 = \begin{pmatrix}x\amp y\end{pmatrix} \begin{pmatrix} a\amp b\\ b\amp c \end{pmatrix} \begin{pmatrix} x\\ y \end{pmatrix}}
      \boxed{A\text{ positive definite} \Longleftrightarrow \mathbf x^T A\mathbf x\gt 0 \text{ for every }\mathbf x\ne\mathbf 0}
      \boxed{D=f_{xx}f_{yy}-f_{xy}^2}
      \boxed{ \begin{array}{c|c} D\gt 0,\ f_{xx}\gt 0 \amp \text{local minimum}\\ D\gt 0,\ f_{xx}\lt 0 \amp \text{local maximum}\\ D\lt 0 \amp \text{saddle}\\ D=0 \amp \text{inconclusive} \end{array} }
