[5-5 title sec-6-limits-in-several-variables default_required]
Limits in several variables

[7-12 p sec-6-limits-in-several-variables default_required]
gave us graphs, level curves,
    and level surfaces. Those pictures help us see scalar fields, but a picture is still a
    promise made from a distance. Limits ask a more delicate question:
    \text{What happens as the input gets very close to one point?}

[14-18 p sec-6-limits-in-several-variables default_required]
In single-variable calculus, x\to a meant approaching from the left and from the
    right. In the plane, a point can approach from every direction: along lines, curves,
    spirals, parabolas, and paths we have not thought to name.

[21-21 title c6s3-subsec-approaching-along-many-paths default_required]
Approaching a point along many paths

[23-28 p c6s3-subsec-approaching-along-many-paths default_required]
Consider the function
      A(x,y)=\frac{x^2-y^2}{x^2+y^2}, \qquad (x,y)\ne(0,0).
      The formula is not defined at the origin. But we can ask whether the values settle down
      as (x,y) approaches (0,0).

[30-35 p c6s3-subsec-approaching-along-many-paths default_required]
Approach along the x-axis. Then y=0, so
      A(x,0)=\frac{x^2}{x^2}=1
      for x\ne0. Along this path, the values approach
      1.

[37-42 p c6s3-subsec-approaching-along-many-paths default_required]
Approach along the y-axis. Then x=0, so
      A(0,y)=\frac{-y^2}{y^2}=-1
      for y\ne0. Along this path, the values approach
      -1.

[44-48 p c6s3-subsec-approaching-along-many-paths default_required]
The same point gives two different limiting answers:
      1 \qquad\text{and}\qquad -1.
      So the function has no limit at the origin.

[51-51 caption c6s3-fig-different-paths-different-limits default_required]
A two-variable limit must survive every possible approach to the point.

[53-73 latex-image c6s3-fig-different-paths-different-limits default_required]

[77-80 p c6s3-subsec-approaching-along-many-paths default_required]
This is the main new issue. A two-variable limit is not a left-right test. It is an
      all-paths test.

[83-83 title checkpoint-6-3-counting-approaches default_required]
How many ways in?

[85-90 p checkpoint-6-3-counting-approaches default_required]
In single-variable calculus, checking a limit means looking from just two sides: the
          left and the right. As a point (x,y) approaches (0,0) in the plane, how
          many genuinely different ways can it approach? Why does this make a two-variable limit
          harder to confirm than a one-variable limit?

[93-98 p checkpoint-6-3-counting-approaches hint]
Picture every line, curve, spiral, and wandering path that ends at the point. On a
          line you have only two directions; in the plane you have a whole circle of directions,
          and curved paths beyond those. Think about how many of these the function must satisfy
          at once.

[103-103 title c6s3-def-limit-two-variables default_required]
Limit of a function of two variables

[105-112 p c6s3-def-limit-two-variables default_required]
Let
          f:D\subseteq\mathbb R^2\to\mathbb R.
          We write
          \boxed{ \lim_{(x,y)\to(a,b)} f(x,y)=L }
          if the values f(x,y) get arbitrarily close to L whenever (x,y)
          is sufficiently close to (a,b), with (x,y)\ne(a,b).

[113-116 p c6s3-def-limit-two-variables default_required]
All nearby inputs must lie in D. We assume that points of D other than (a,b) occur arbitrarily close to (a,b); such a point is called an accumulation point of D. The point (a,b) does not have to be in the domain of f. A limit is
          about nearby points, not necessarily the point itself.

[120-123 p c6s3-subsec-approaching-along-many-paths default_required]
The phrase whenever (x,y) is sufficiently close means from every direction
      and along every path. If even one path gives a different answer, the limit fails.

[127-127 title c6s3-subsec-path-tests-nonexistence default_required]
Path tests for nonexistence of a limit

[129-132 p c6s3-subsec-path-tests-nonexistence default_required]
A path is a curve approaching the point. If a limit exists, every path must see the same
      limiting value.

[134-134 p c6s3-subsec-path-tests-nonexistence default_required]
The quickest way to disprove a limit is to find two paths that disagree.

[137-137 title c6s3-ex-family-straight-paths default_required]
A family of straight paths

[139-145 p c6s3-ex-family-straight-paths default_required]
Let
          B(x,y)=\frac{xy}{x^2+y^2}, \qquad (x,y)\ne(0,0).
          Along the x-axis,
          B(x,0)=0.
          So along that path, the values approach 0.

[146-152 p c6s3-ex-family-straight-paths default_required]
Along the line
          y=x,
          we get
          B(x,x)=\frac{x^2}{x^2+x^2}=\frac12.
          So along that path, the values approach \frac12.

[153-157 p c6s3-ex-family-straight-paths default_required]
The two path limits disagree. Therefore
          \lim_{(x,y)\to(0,0)}\frac{xy}{x^2+y^2}
          does not exist.

[161-172 p c6s3-subsec-path-tests-nonexistence default_required]
The same function shows something stronger. Along the line
      y=mx,
      we get
      
        B(x,mx) \amp= \frac{x(mx)}{x^2+(mx)^2}
        \amp= \frac{mx^2}{(1+m^2)x^2}
        \amp= \frac{m}{1+m^2},
      
      for x\ne0. Different slopes m give different limiting values. The origin is
      not approached by one road; it is approached by infinitely many roads.

[175-175 title c6s3-thm-path-test-nonexistence default_required]
Path test for nonexistence

[177-183 p c6s3-thm-path-test-nonexistence default_required]
Let
          f:D\subseteq\mathbb R^2\to\mathbb R.
          Suppose two paths
          \mathbf r_1(t)\to(a,b), \qquad \mathbf r_2(t)\to(a,b)
          as t\to0, and suppose that, for sufficiently small nonzero t, the paths stay in the domain of f and avoid (a,b).

[184-192 p c6s3-thm-path-test-nonexistence default_required]
If
          \lim_{t\to0} f(\mathbf r_1(t))
          and
          \lim_{t\to0} f(\mathbf r_2(t))
          exist but are different, then
          \lim_{(x,y)\to(a,b)} f(x,y)
          does not exist.

[195-199 p c6s3-thm-path-test-nonexistence default_required]
If the two-variable limit were L, then f(x,y) would approach L
          whenever (x,y) approaches (a,b). In particular, it would approach
          L along every path to (a,b).

[200-203 p c6s3-thm-path-test-nonexistence default_required]
Two different path limits would force the same limit to equal two different numbers.
          That is impossible.

[207-210 p c6s3-subsec-path-tests-nonexistence default_required]
The theorem is a tool for showing that a limit does not exist. It is not a tool for
      proving that a limit exists.

[213-213 title checkpoint-6-3-two-paths-asymmetry default_required]
Why is disproving easier than proving?

[215-220 p checkpoint-6-3-two-paths-asymmetry default_required]
Finding two paths that approach (a,b) with different limiting values
          settles the matter: the limit does not exist. Yet finding two paths that
          agree tells us almost nothing about whether the limit exists. Why is there
          this asymmetry between the two situations?

[223-228 p checkpoint-6-3-two-paths-asymmetry hint]
A limit must equal the same number along every approach. To break that, one
          conflict is enough. To confirm it, no finite collection of agreeing paths can speak for
          all the infinitely many paths you did not test — an untested path might still
          disagree.

[232-232 p c6s3-subsec-path-tests-nonexistence default_required]
Here is the trap.

[235-235 title c6s3-ex-straight-paths-agree-limit-fails default_required]
All straight paths agree, but the limit still fails

[237-253 p c6s3-ex-straight-paths-agree-limit-fails default_required]
Define
          C(x,y)=\frac{x^2y}{x^4+y^2}, \qquad (x,y)\ne(0,0).
          First approach along a straight line
          y=mx.
          If m=0, then
          C(x,0)=0.
          If m\ne0, then
          
            C(x,mx) \amp= \frac{x^2(mx)}{x^4+m^2x^2}
            \amp= \frac{mx^3}{x^2(x^2+m^2)}
            \amp= \frac{mx}{x^2+m^2}.
          
          As x\to0,
          \frac{mx}{x^2+m^2}\to0.
          The vertical line x=0 also gives zero. So every straight-line path gives the limiting value 0.

[254-264 p c6s3-ex-straight-paths-agree-limit-fails default_required]
But now approach along the parabola
          y=x^2.
          Then
          
            C(x,x^2) \amp= \frac{x^2(x^2)}{x^4+(x^2)^2}
            \amp= \frac{x^4}{2x^4}
            \amp= \frac12.
          
          Along this curved path, the limiting value is \frac12.

[265-268 p c6s3-ex-straight-paths-agree-limit-fails default_required]
So the full limit does not exist, even though every straight-line test gave 0.
          Straight roads are not enough.

[272-272 p c6s3-subsec-path-tests-nonexistence default_required]
The moral is important:

[274-279 p c6s3-subsec-path-tests-nonexistence default_required]
\text{Different path limits disprove a limit.}
      But
      \text{matching path limits along a few paths do not prove a limit.}
      To prove a limit, we need a method that controls all approaches at once.

[283-283 title c6s3-subsec-polar-coordinate-tests default_required]
Polar-coordinate tests near the origin

[285-295 p c6s3-subsec-polar-coordinate-tests default_required]
Near the origin, polar coordinates are built for limits. Every point near (0,0)
      can be written as
      x=r\cos\theta,\qquad y=r\sin\theta,
      where
      r=\sqrt{x^2+y^2}.
      Approaching the origin means
      r\to0.
      The angle \theta may stay fixed, change, or spin wildly. A good polar argument
      must work no matter what \theta does.

[298-298 title c6s3-ex-polar-proof-of-limit default_required]
A polar-coordinate proof of a limit

[300-305 p c6s3-ex-polar-proof-of-limit default_required]
Let
          D(x,y)=\frac{x^2y}{x^2+y^2}, \qquad (x,y)\ne(0,0).
          We want to find
          \lim_{(x,y)\to(0,0)}D(x,y).

[306-324 p c6s3-ex-polar-proof-of-limit default_required]
Use polar coordinates:
          x=r\cos\theta,\qquad y=r\sin\theta.
          Then
          
            D(x,y) \amp= \frac{(r\cos\theta)^2(r\sin\theta)}{r^2}
            \amp= r\cos^2\theta\sin\theta.
          
          Therefore
          |D(x,y)| = |r\cos^2\theta\sin\theta|.
          Since
          |\cos^2\theta\sin\theta|\le1,
          we get
          |D(x,y)|\le r.
          As (x,y)\to(0,0), we have r\to0. So
          |D(x,y)|\le r\to0.
          By the squeeze idea from single-variable calculus,
          \boxed{ \lim_{(x,y)\to(0,0)}\frac{x^2y}{x^2+y^2}=0. }

[328-331 p c6s3-subsec-polar-coordinate-tests default_required]
The key was not merely rewriting in polar coordinates. The key was finding a bound that
      did not depend on \theta.

[334-334 title c6s3-thm-polar-squeeze-test default_required]
Polar squeeze test near the origin

[336-347 p c6s3-thm-polar-squeeze-test default_required]
Suppose
          f(x,y)
          is defined near (0,0), except possibly at (0,0). Write
          x=r\cos\theta,\qquad y=r\sin\theta.
          If there is a function g(r) such that
          |f(r\cos\theta,r\sin\theta)-L|\le g(r)
          for all sufficiently small r\gt0 and all angles \theta, and if
          \lim_{r\to0^+}g(r)=0,
          then
          \boxed{ \lim_{(x,y)\to(0,0)}f(x,y)=L. }

[350-358 p c6s3-thm-polar-squeeze-test default_required]
The distance from (x,y) to the origin is r. As (x,y)\to(0,0), we
          have r\to0^+. The inequality
          |f(r\cos\theta,r\sin\theta)-L|\le g(r)
          holds for every angle, so it controls every possible approach to the origin. Since
          g(r)\to0, the difference
          |f(x,y)-L|
          must also go to 0.

[362-365 p c6s3-subsec-polar-coordinate-tests default_required]
The phrase for all angles \theta is the heart of the theorem. Without it, a
      path could hide in the angle dependence.

[368-368 title c6s3-ex-polar-reveals-failure default_required]
Polar coordinates can also reveal failure

[370-380 p c6s3-ex-polar-reveals-failure default_required]
Return to
          A(x,y)=\frac{x^2-y^2}{x^2+y^2}.
          In polar coordinates,
          
            A(x,y) \amp= \frac{r^2\cos^2\theta-r^2\sin^2\theta}{r^2}
            \amp= \cos^2\theta-\sin^2\theta
            \amp= \cos(2\theta).
          
          The expression does not depend on r at all. It depends only on the angle.

[381-388 p c6s3-ex-polar-reveals-failure default_required]
Along \theta=0,
          A=1.
          Along \theta=\frac{\pi}{2},
          A=-1.
          No matter how close we get to the origin, the angle still controls the value. So the
          limit does not exist.

[392-399 p c6s3-subsec-polar-coordinate-tests default_required]
To use polar coordinates near another point (a,b), shift the point to the origin:
      u=x-a,\qquad v=y-b.
      Then write
      u=r\cos\theta,\qquad v=r\sin\theta.
      Approaching (a,b) is the same as
      r=\sqrt{(x-a)^2+(y-b)^2}\to0.

[403-403 title c6s3-subsec-formal-limit-definition-rn default_required]
The formal limit definition in \mathbb R^n

[405-408 p c6s3-subsec-formal-limit-definition-rn default_required]
The words nearby inputs give nearby outputs are right, but sometimes we need the
      exact sentence behind them.

[410-414 p c6s3-subsec-formal-limit-definition-rn default_required]
For a function
      F:D\subseteq\mathbb R^n\to\mathbb R^m,
      both the input and the output may be vectors. Distance measures closeness in both spaces.

[417-417 title c6s3-def-formal-limit-rn default_required]
Formal limit in \mathbb R^n

[419-419 p c6s3-def-formal-limit-rn default_required]
We assume \mathbf a is an accumulation point of the domain: for every \delta>0, some \mathbf x\in D satisfies 0<\|\mathbf x-\mathbf a\|<\delta.

[420-426 p c6s3-def-formal-limit-rn default_required]
Let
          F:D\subseteq\mathbb R^n\to\mathbb R^m.
          We write
          \boxed{ \lim_{\mathbf x\to\mathbf a}F(\mathbf x)=\mathbf L }
          if the following condition holds:

[427-434 p c6s3-def-formal-limit-rn default_required]
For every \varepsilon\gt0, there is a \delta\gt0 such that whenever
          0\lt\|\mathbf x-\mathbf a\|\lt\delta
          and
          \mathbf x\in D,
          we have
          \|F(\mathbf x)-\mathbf L\|\lt\varepsilon.

[438-445 p c6s3-subsec-formal-limit-definition-rn default_required]
This definition is just the precise version of the all-paths idea. The condition
      0\lt\|\mathbf x-\mathbf a\|\lt\delta
      says that the input is close to \mathbf a, but not equal to \mathbf a. The
      condition
      \|F(\mathbf x)-\mathbf L\|\lt\varepsilon
      says that the output is close to \mathbf L.

[448-448 title checkpoint-6-3-epsilon-delta-guarantee default_required]
What does \varepsilon-\delta demand?

[450-455 p checkpoint-6-3-epsilon-delta-guarantee default_required]
Checking a few paths, or even infinitely many along one family, can never list every
          possible approach. What does the \varepsilon-\delta definition require
          that path-checking cannot guarantee? In particular, think about what the single number
          \delta must control.

[458-463 p checkpoint-6-3-epsilon-delta-guarantee hint]
The condition 0\lt\|\mathbf x-\mathbf a\|\lt\delta describes a whole
          punctured disk around \mathbf a, not a curve. So one \delta must force
          \|F(\mathbf x)-\mathbf L\|\lt\varepsilon for all points in that
          disk at once — every path through it included.

[468-468 title c6s3-ex-direct-limit-linear-function default_required]
A direct limit proof for a linear function

[470-496 p c6s3-ex-direct-limit-linear-function default_required]
Let
          f(x,y)=3x-2y.
          We claim that
          \lim_{(x,y)\to(1,4)} f(x,y)=f(1,4)=-5.
          Compute the difference:
          
            |f(x,y)-(-5)| \amp= |3x-2y+5|
            \amp= |3(x-1)-2(y-4)|.
          
          Using the triangle inequality,
          |3(x-1)-2(y-4)| \le 3|x-1|+2|y-4|.
          Also,
          |x-1|\le \sqrt{(x-1)^2+(y-4)^2},
          and
          |y-4|\le \sqrt{(x-1)^2+(y-4)^2}.
          Therefore
          |f(x,y)-(-5)| \le 5\sqrt{(x-1)^2+(y-4)^2}.
          If
          \sqrt{(x-1)^2+(y-4)^2}\lt\delta,
          then
          |f(x,y)-(-5)|\lt5\delta.
          To make this less than \varepsilon, choose
          \delta=\frac{\varepsilon}{5}.
          So the formal definition confirms what geometry already suggested: a linear function
          has no sudden behavior. Its values move continuously with its inputs.

[500-503 p c6s3-subsec-formal-limit-definition-rn default_required]
Vector-valued limits work component by component, just as they did for the one-variable
      vector-valued functions in .

[506-506 title c6s3-thm-componentwise-limits default_required]
Componentwise limits

[508-520 p c6s3-thm-componentwise-limits default_required]
Let
          F:D\subseteq\mathbb R^n\to\mathbb R^m
          be written in components as
          F(\mathbf x)= \bigl(F_1(\mathbf x),F_2(\mathbf x),\ldots,F_m(\mathbf x)\bigr).
          Let
          \mathbf L=(L_1,L_2,\ldots,L_m).
          Then
          \lim_{\mathbf x\to\mathbf a}F(\mathbf x)=\mathbf L
          if and only if
          \lim_{\mathbf x\to\mathbf a}F_i(\mathbf x)=L_i
          for every component i=1,2,\ldots,m.

[523-527 p c6s3-thm-componentwise-limits default_required]
If the vector F(\mathbf x) approaches \mathbf L, then the distance
          between them goes to 0. Each component difference is no larger in absolute
          value than that distance, so each component approaches its limiting value.

[528-532 p c6s3-thm-componentwise-limits default_required]
Conversely, if each component difference approaches 0, then
          \|F(\mathbf x)-\mathbf L\| = \sqrt{ (F_1(\mathbf x)-L_1)^2+\cdots+(F_m(\mathbf x)-L_m)^2 }
          also approaches 0. So the vector limit holds.

[537-537 title c6s3-ex-vector-valued-limit default_required]
A vector-valued limit

[539-548 p c6s3-ex-vector-valued-limit default_required]
Let
          F(x,y)= \left( x+y,\; \frac{x^2y}{x^2+y^2} \right), \qquad (x,y)\ne(0,0).
          As (x,y)\to(0,0),
          x+y\to0.
          From the polar-coordinate example above,
          \frac{x^2y}{x^2+y^2}\to0.
          Therefore
          \lim_{(x,y)\to(0,0)}F(x,y)=(0,0).

[552-555 p c6s3-subsec-formal-limit-definition-rn default_required]
A limit does not care what happens at the point itself. That is both useful and a little
      dangerous.

[557-566 p c6s3-subsec-formal-limit-definition-rn default_required]
For example, define
      G(x,y)= \begin{cases} \dfrac{x^2y}{x^2+y^2}, & (x,y)\ne(0,0),\\[2mm] 17, & (x,y)=(0,0). \end{cases}
      The limit at the origin is still
      0.
      But the actual value at the origin is
      17.
      So the surface has a perfectly good limiting height, but the function has placed the point
      at the wrong height.

[568-572 p c6s3-subsec-formal-limit-definition-rn default_required]
That mismatch is exactly what continuity is designed to catch. A limit asks what the
      nearby values want the answer to be. Continuity asks whether the function actually
      listens.
