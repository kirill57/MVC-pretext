Lemma 13.6.7 Differentiating an integral with a parameter.

Suppose \(q(x,t)\) and \(q_x(x,t)\) are continuous on a neighborhood of \([a,b]\times[c,d]\text{.}\) For \(a\lt x\lt b\text{,}\)
\begin{equation*} H(x)=\int_c^d q(x,t)\,dt \quad\Longrightarrow\quad H'(x)=\int_c^d q_x(x,t)\,dt. \end{equation*}
The same conclusion holds for any fixed subinterval of \([c,d]\text{.}\)
🔗
🔗

Explanation using a supplied uniform-control fact.
We use this fact: a continuous function on a closed bounded rectangle is uniformly continuous. This means that one allowed input distance works at every point of the rectangle for a prescribed output error. The fact is supplied here; Checkpoint F.10.2 gives an optional proof.
🔗
Fix an interior \(x\text{.}\) Applied to \(q_x\) on a small closed rectangle around \(\{x\}\times[c,d]\text{,}\) the fact gives \(|q_x(x+s,t)-q_x(x,t)|\le\varepsilon\) for all \(t\in[c,d]\) whenever \(|s|\) is sufficiently small. The one-variable Mean Value Theorem, with \(t\) fixed, therefore gives
\begin{equation*} \left|\frac{q(x+h,t)-q(x,t)}{h}-q_x(x,t)\right|\le\varepsilon. \end{equation*}
One bound works for every integration-variable value at once. Hence
\begin{equation*} \left|\frac{H(x+h)-H(x)}{h}-\int_c^d q_x(x,t)\,dt\right| \le(d-c)\varepsilon. \end{equation*}
As the error can be made arbitrarily small, this proves the formula using the supplied fact. Pointwise convergence alone would not justify this step.
