Aside: Optional: oriented-volume connection.

A covector is a linear scalar measurement on vectors. If \(\alpha,\beta,\gamma\) are three covectors on the same vector space, define their triple wedge by its value on an ordered triple \((u,v,w)\text{:}\)
\begin{equation*} (\alpha\wedge\beta\wedge\gamma)(u,v,w)= \det\begin{pmatrix} \alpha(u)&\alpha(v)&\alpha(w)\\ \beta(u)&\beta(v)&\beta(w)\\ \gamma(u)&\gamma(v)&\gamma(w) \end{pmatrix}. \end{equation*}
Linearity in each row makes this expression linear in each covector. Swapping two covectors changes its sign, and repeated covectors give zero. We also use \((\alpha\wedge\beta)\wedge\gamma\) for this triple determinant. This convention suffices here; it is not a construction of wedge multiplication in all degrees.
🔗
For variable coefficients, evaluate all covectors at the same fixed parameter point. Here \(dx\) means the differential of the scalar function \(x(r,\theta,z)\) on the parameter domain, and similarly for \(dy\text{;}\) \(dz\) is its height-coordinate measurement. Thus all three act on the same parameter vectors. We have
\begin{equation*} dx=\cos\theta\,dr-r\sin\theta\,d\theta,\qquad dy=\sin\theta\,dr+r\cos\theta\,d\theta. \end{equation*}
Multilinearity, alternation and the two-covector rule give
\begin{equation*} dx\wedge dy=r\,dr\wedge d\theta,\qquad dx\wedge dy\wedge dz=r\,dr\wedge d\theta\wedge dz. \end{equation*}
The wedge expression records orientation in order \((r,\theta,z)\text{;}\) ordinary volume uses the absolute determinant. Iterated integration order alone does not specify orientation. Section 12.5 develops explicit pullback notation for this substitution.
